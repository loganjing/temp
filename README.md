# 专注时段记录（143-timeline）

单页面的日常专注记录系统：内置番茄钟倒计时（25 分钟专注 + 5 分钟休息），每完成一个番茄钟自动记入当日列表；页面上方显示当日累计专注时长，下方展示当日各时段专注热力图与当日记录列表。

## 功能范围

| 区域 | 内容 |
|---|---|
| 上方 | 当日累计专注时长、已完成番茄钟数量、最近一次专注时间范围、统计口径（本地自然日） |
| 中部 | 番茄钟：专注 25 分钟 → 自动进入休息 5 分钟 → 回到可再次开始的专注状态；提供开始、暂停/继续、重置当前时段 |
| 下方 | 当日各时段专注热力图（按小时划分全天 24 个时段，颜色深浅对应专注时长，附时间轴与颜色说明）与当日专注记录列表 |

行为规则：

- 只有专注倒计时自然结束后才写入一条当日记录；未走完即重置或放弃的时段不产生记录。
- 记录、累计时长与热力图均以本地自然日为口径；跨过本地零点后自动面向新的一天。
- 记录保存在浏览器 `localStorage`（键名 `focus_records_<YYYY-MM-DD>`），刷新或重新打开页面后仍可读取；不跨浏览器、不跨设备、不跨用户共享。
- 番茄钟运行状态（当前阶段、剩余时间、运行/暂停）仅存于内存，刷新后回到专注待开始状态。

## 运行方式

```bash
npm install      # 安装依赖
npm run dev      # 启动开发服务器（默认 http://127.0.0.1:5173）
npm run build    # 类型检查 + 构建静态产物到 dist/
npm run preview  # 预览构建产物
```

## 开发检查

```bash
npm run typecheck  # TypeScript 类型检查
npm test           # 单元测试（专注/休息轮转、记录读写、热力图聚合、展示格式化）
npm run build      # 类型检查 + 生产构建
```

## 验证辅助参数

默认时长始终为 25 分钟专注 + 5 分钟休息。为便于在可接受的等待时间内走完完整番茄钟流程，可用 URL 参数临时缩短倒计时（不改变默认行为）：

```text
http://127.0.0.1:5173/?focusSeconds=3&breakSeconds=2
```

显式提供参数时，页面会显示提示说明当前为验证用缩短时长。非法值（非数字、非正数）自动回退到默认时长。

src/lib/config.ts     默认时长与验证辅助参数
