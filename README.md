# 实时时钟页面

页面实时显示当前时、分、秒（HH:MM:SS 格式），每秒自动刷新。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173` 即可看到实时时钟。

## 功能

- 页面打开后立即显示当前时间并自动开始每秒刷新。
- 页面切到后台（不可见）时暂停定时器，切回后立即恢复并同步到当前时间。
- 组件卸载时自动清理定时器，无内存泄漏。

## 构建

```bash
npm run build    # 输出到 dist/
npm run preview  # 预览构建产物
```

## 技术栈

React 18 + Vite 6
