# 教师管理系统

单用户教师信息 CRUD 管理应用（任务：129-teacher / WorkItem: wi-t1000325）。

## 功能

- 教师列表：表格展示教师名称、教授课程、年级、手机、邮箱五个字段，并提供编辑、删除入口。
- 新增教师：录入五个字段后保存，保存成功回到列表并可查看到该记录。
- 编辑教师：表单预填当前字段值，修改保存后列表显示更新后的值。
- 删除教师：删除前弹确认框，确认后记录从列表移除。

数据持久化在浏览器 `localStorage`（键：`teacher-management.teachers.v1`），仅保存在当前浏览器，不与其他设备或用户共享。

## 技术栈

React 19 + Vite 6 + TypeScript；单元测试使用 Vitest（jsdom 环境）。

## 运行

```bash
npm install

# 开发模式（本地访问入口）
npm run dev

# 类型检查 + 生产构建
npm run build

# 单元测试
npm test
```

## 校验规则

- 教师名称必填（空白视为空，不允许保存）。
- 手机按基本手机号格式（数字、可选 “+” 前缀、6-20 位）做提示性校验；邮箱按基本邮箱格式做提示性校验。
- 教授课程、年级不做强制约束，仅去除首尾空白后保存。
- 校验失败时在表单内提示，不执行写入。
