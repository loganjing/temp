# 教师管理系统

一个基于 React + Vite 的教师管理系统，支持教师信息的增删改查操作。

## 功能

- **新增教师**：录入教师名称、教授课程、年级、手机、邮箱信息
- **查看教师列表**：以表格形式展示所有教师记录
- **编辑教师**：修改已有教师记录并保存
- **删除教师**：删除指定教师记录（含确认提示）

## 字段说明

| 字段 | 说明 | 校验 |
|------|------|------|
| 教师名称 | 教师姓名 | 必填 |
| 教授课程 | 教授的课程 | 选填 |
| 年级 | 所教年级 | 选填 |
| 手机 | 手机号码 | 基本格式校验（11 位数字） |
| 邮箱 | 电子邮箱 | 基本格式校验（含 @ 及域名） |

## 技术栈

- React 18
- Vite 5
- localStorage 数据持久化

## 开发运行

```bash
npm install
npm run dev
```

浏览器访问 http://localhost:5173

## 构建

```bash
npm run build
```

构建产物输出到 `dist/` 目录。
