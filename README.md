# 教师管理系统

一个基于 React + Vite 的单页教师管理应用，支持教师的增删改查操作。

## 功能

- **教师列表**：以表格展示所有教师记录，包含教师名称、教授课程、年级、手机、邮箱
- **新增教师**：填写表单保存新记录，支持字段校验
- **编辑教师**：修改已有教师记录字段并保存
- **删除教师**：删除前需用户确认

## 字段说明

| 字段 | 说明 | 校验规则 |
|------|------|----------|
| 教师名称 | 教师姓名 | 必填 |
| 教授课程 | 所教授课程 | 必填 |
| 年级 | 负责年级 | 必填 |
| 手机 | 手机号码 | 必填，11位有效手机号 |
| 邮箱 | 电子邮箱 | 必填，标准邮箱格式 |

## 技术栈

- React 18
- Vite 5
- 浏览器 localStorage 持久化

## 开发

```bash
npm install
npm run dev
```

应用默认运行在 http://localhost:5173

## 构建

```bash
npm run build
```

构建产物输出到 `dist/` 目录。
