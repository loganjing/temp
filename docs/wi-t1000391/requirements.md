# 需求文档：贪吃蛇游戏（193-snake）

## 1. 目标

开发一个经典贪吃蛇游戏，玩家通过控制蛇的移动方向吃掉食物，蛇身随进食增长，碰到墙壁或自身则游戏结束。

- **用户明确提出**：开发一个贪吃蛇游戏。
- **未规定**：技术栈、平台载体（Web/桌面/移动）、部署方式、美术风格、难度等级、排行榜等均未由用户指定，不在当前基线范围内。

## 2. 核心行为与规则

### 2.1 游戏区域

- 游戏在一个有边界的网格区域内进行。蛇和食物均占据网格中的单元格。

### 2.2 蛇的移动

- 蛇初始为固定长度，在游戏区域内以固定速度持续移动。
- 蛇的移动方向为上、下、左、右四个方向之一。
- 玩家可在蛇移动过程中改变方向，但不能直接反向（例如当前向右移动时不能立即变为向左）。

### 2.3 食物与进食

- 游戏区域内始终存在一个食物，位于空单元格中。
- 蛇头移动到食物所在单元格时，食物被吃掉，蛇身增长一节，并在剩余空单元格中重新生成一个食物。

### 2.4 游戏结束条件

- 蛇头移动到游戏区域边界（撞墙）时，游戏结束。
- 蛇头移动到蛇身或蛇尾所在单元格（撞自身）时，游戏结束。

### 2.5 分数

- 每吃掉一个食物，分数增加。
- 游戏结束时显示最终分数。

### 2.6 游戏控制

- 游戏开始时蛇即开始移动。
- 游戏结束后，玩家可以重新开始一局新游戏。

## 3. 验收场景

### AC-01：玩家可控制蛇移动并吃食物增长得分

- 验收条件：玩家能通过方向控制改变蛇的移动方向，吃到食物后蛇身增长且分数增加。
- 入口类型：用户界面
- 验证动作：启动游戏并使用方向控制操作蛇吃到至少一个食物。
- 预期结果：蛇身长度增加一节，分数相应增加，游戏继续进行。
- 证据类型：interaction, runtime-render

### AC-02：蛇撞墙或撞自身时游戏结束并显示分数

- 验收条件：蛇头触及边界或自身时游戏结束，并显示最终得分。
- 入口类型：用户界面
- 验证动作：操作蛇使其撞向墙壁或自身。
- 预期结果：蛇停止移动，显示游戏结束状态及最终分数。
- 证据类型：interaction, runtime-render

### AC-03：游戏结束后可重新开始新一局

- 验收条件：游戏结束后玩家能重新开始一局新游戏，蛇恢复初始长度，分数归零。
- 入口类型：用户界面
- 验证动作：在游戏结束状态下触发重新开始。
- 预期结果：游戏区域重置，蛇恢复初始长度与位置，分数归零，蛇开始移动。
- 证据类型：interaction, runtime-render
