# 教师管理系统 架构基线（142-teachers）

> 引用批准的需求基线：`docs/wi-t1000004/requirements.md`（SHA-256 `c067b511caa5dd9daf9f82f38225d4f831018bfe933af605f5dd6ca4e14445bf`）

## 应用类型

单用户简单前端应用（simple-frontend）。无服务端、无数据库、无认证、无后台任务、无外部集成。

## 技术选型

| 项目 | 选型 |
|------|------|
| 应用形态 | React + Vite 单页应用（SPA） |
| 数据存储 | 浏览器 `localStorage` |
| 运行方式 | Vite 开发服务器（`npm run dev`） |

## 页面与交互范围

应用为单页面，包含以下交互区域：

1. **教师列表区**：以表格展示所有已存教师记录（教师名称、教授课程、年级、手机、邮箱），每行附带「编辑」「删除」操作按钮；列表上方放置「新增教师」按钮。
2. **教师表单区（新增/编辑）**：弹出或内联表单，包含教师名称（必填）、教授课程、年级、手机（基本格式校验）、邮箱（基本格式校验）五个字段，支持保存与取消。

交互流程覆盖需求中定义的增、删、改、查全部操作。

## 数据归属

- 所有教师数据存储在当前浏览器的 `localStorage` 中，使用一个明确的应用命名键（如 `teacher-management:teachers`）。
- 数据在同一浏览器配置文件中刷新或重新打开页面后仍保留；不与其他浏览器、设备或用户共享。
- 数据格式为 JSON 数组，每个元素为一个教师记录对象。

## 接口与校验边界

- **读取**：应用启动时从 `localStorage` 加载教师列表；新增/编辑/删除操作后同步写回。
- **新增**：校验通过后将新记录追加到数组并写回 `localStorage`，刷新列表。
- **编辑**：校验通过后更新对应记录并写回 `localStorage`，刷新列表。
- **删除**：从数组中移除对应记录并写回 `localStorage`，刷新列表。
- **校验**：教师名称必填；手机号进行基本格式校验（数字长度合理）；邮箱进行基本格式校验（包含 `@` 与域名）。校验不通过时阻止保存并提示对应字段。

## 实现入口

- 新建 React/Vite 应用，入口为 `src/main.tsx`（或 `src/main.jsx`）。
- 开发运行：`npm run dev`，由 Vite 开发服务器提供本地预览。
- 不涉及服务端 API、数据库、认证服务或外部服务调用。
