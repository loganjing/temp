# 架构基线：实时时钟页面

## 需求基线

本文档基于已批准的需求快照 `docs/wi-t1000026/requirements.md`（SHA-256: `2c6265c675802b5bd1fa3de0eb7c95ccdf212dbd5d22e54e6bfe94b3a57525b4`）进行设计，不扩展或重裁产品语义。

## 应用类型

**simple-frontend** — 纯前端单页应用，无服务端、数据库、认证、后台任务或外部集成。

## 页面与交互范围

- 单一页面，页面加载后立即显示当前系统时间，格式为 `时:分:秒`（如 `14:05:09`）。
- 时间显示每隔 1 秒自动刷新，与系统时间保持同步，无需用户手动操作。
- 页面持续打开期间时间不断更新，关闭页面后停止更新，重新打开后恢复显示。

## 浏览器状态与数据归属

- 页面不持久化任何数据。时间值由浏览器 `Date` API 从系统时钟实时读取，每次渲染时重新获取当前时间。
- 不使用 `localStorage` 或其他存储机制。时间不跨会话保存，也不跨浏览器/设备/用户共享。
- 组件内部仅维护一个用于触发重渲染的定时器状态（秒级 tick），不承载业务数据。

## 实现入口

- 使用 React + Vite 构建 SPA。
- 入口文件：`src/main.jsx`（或 `.tsx`），挂载到 `index.html` 的根容器。
- 时钟组件：`src/Clock.jsx`，内部通过 `useEffect` + `setInterval(…, 1000)` 每 1 秒读取 `new Date()` 并更新显示。
- 显示格式化：使用 `String.padStart(2, '0')` 将时、分、秒补零至两位，拼接为 `HH:MM:SS`。

## 运行方式

- 开发环境：`npm run dev`（Vite 开发服务器），在浏览器中打开本地开发地址即可看到实时时钟页面。
- 构建产物：`npm run build`，生成静态资源可部署到任意静态文件服务器。
