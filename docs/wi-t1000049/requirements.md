# 贪吃蛇游戏 需求文档

## 目标

开发一个贪吃蛇游戏，玩家通过方向控制让蛇在游戏区域内移动、吃食物增长，碰撞墙壁或自身时游戏结束。

> 本需求为用户明确提出。游戏载体（Web / 桌面 / 移动）**未规定**，验收以用户界面交互行为为准，不绑定具体平台。

## 核心行为与规则

### 游戏区域与蛇

- 游戏在一个网格区域内进行；蛇由若干节组成，初始长度为一节以上。
- 蛇按当前方向自动持续移动，每个时间步前进一格。

### 方向控制（用户明确提出）

- 玩家通过方向输入（上、下、左、右）改变蛇的移动方向。
- 蛇不能直接反向掉头（例如向右行进时不能立即改为向左）。

### 食物与增长

- 游戏区域内始终存在一份食物，位于蛇身未占据的随机网格位置。
- 蛇头移动到食物所在格时：蛇身增长一节，当前食物消失，新食物在剩余空格中随机生成。

### 分数（推荐基线）

- 吃到一份食物，分数 +1。分数是游戏进行中玩家可观察的进度指标，其具体显示位置和样式未规定。

### 碰撞与结束

- 蛇头移动到游戏区域边界外（撞墙）时，游戏结束。
- 蛇头移动到蛇身已占据的格子（撞自身）时，游戏结束。
- 游戏结束后显示最终分数，并提供重新开始的方式。

### 游戏开始与重新开始（推荐基线）

- 游戏提供开始入口；开始后蛇从初始位置以初始方向移动。
- 游戏结束后玩家可选择重新开始，重新开始时蛇恢复初始长度、分数归零、食物重新生成。

## 验收场景

### AC-01：蛇按方向输入移动且不可直接掉头

- 验收条件：蛇持续自动移动，玩家可通过方向输入改变蛇的移动方向，且蛇不能直接反向掉头。
- 入口类型：用户界面
- 验证动作：游戏开始后，连续输入若干方向（含尝试反向掉头的操作），观察蛇的移动方向。
- 预期结果：蛇按当前方向持续移动；输入有效方向后蛇转向该方向行进；输入与当前方向相反的方向时蛇保持原方向不掉头。
- 证据类型：interaction, runtime-render

### AC-02：蛇吃到食物后增长且分数增加

- 验收条件：蛇头到达食物所在格时，蛇身增长一节、分数 +1、新食物在空位生成。
- 入口类型：用户界面
- 验证动作：控制蛇移动至当前食物位置，观察蛇身长度、分数和食物位置变化。
- 预期结果：蛇身增长一节；分数增加 1；原食物消失并在蛇身未占据的空格中出现新食物。
- 证据类型：interaction, runtime-render

### AC-03：撞墙或撞自身时游戏结束并显示最终分数

- 验收条件：蛇头越出游戏区域边界或与蛇身重叠时，游戏结束并显示最终分数。
- 入口类型：用户界面
- 验证动作：分别触发蛇头撞向边界和撞向蛇身两种情形，观察游戏状态与显示内容。
  - 子条件 a：蛇头移动到区域边界外。
  - 子条件 b：蛇头移动到蛇身已占据的格子。
- 预期结果：两种情形下游戏均结束；游戏区域呈现结束状态并显示最终分数。
- 证据类型：interaction, runtime-render

### AC-04：游戏结束后可重新开始

- 验收条件：游戏结束后，玩家可触发重新开始，蛇恢复初始长度、分数归零、食物重新生成。
- 入口类型：用户界面
- 验证动作：在游戏结束状态下触发重新开始，观察蛇、分数和食物的初始状态。
- 预期结果：蛇恢复初始长度并从初始位置以初始方向移动；分数归零；食物重新生成在空位。
- 证据类型：interaction, runtime-render

## 范围外

- 联机对战、排行榜、多关卡、难度分级等扩展能力均**未规定**，不在当前基线内。
