# 需求文档：贪吃蛇游戏（175-snake）

## 1. 目标

用户明确提出：开发一个贪吃蛇游戏。玩家通过方向控制让蛇在游戏区域中移动，吃食物使蛇身增长，避免撞墙或撞到自身，以获得更高分数为目标。

## 2. 核心行为与规则

以下规则中，用户明确提出的标记为「用户」，游戏固有且为完成核心目标所必需的标记为「推荐基线」。

- **方向控制**（用户）：玩家可通过方向输入改变蛇的移动方向（上、下、左、右）。
- **持续移动**（推荐基线）：蛇按当前方向持续自动移动，玩家不操作时蛇不会停止。
- **反向限制**（推荐基线）：蛇不能直接反向移动（例如向右移动时不能立刻变为向左），防止瞬间撞死自身。
- **食物与增长**（推荐基线）：游戏区域内随机出现一个食物；蛇头吃到食物后，蛇身增长一节，分数增加，并在空白位置生成下一个食物。
- **碰撞与结束**（推荐基线）：蛇头碰到游戏区域边界或蛇身任意一节时，游戏结束。
- **计分**（推荐基线）：每吃到一个食物得分增加；游戏结束时显示最终得分。
- **重新开始**（推荐基线）：游戏结束后玩家可重新开始一局新游戏。
- **未规定事项**：游戏区域大小、移动速度、视觉风格、键盘还是触屏操作的具体交互形式、是否设置难度等级等，用户未明确要求，保持未规定，由实现阶段在合理范围内决定。

## 3. 验收场景

### AC-01：玩家可控制蛇移动、吃食物并增长得分

- 验收条件：玩家能用方向控制让蛇移动，蛇吃到食物后身体增长一节、得分增加，并出现新的食物。
- 入口类型：用户界面
- 验证动作：开始游戏后，通过方向输入控制蛇朝食物方向移动并吃到食物。
- 预期结果：蛇身长度增加一节，分数增加，游戏区域内在空白位置出现新的食物。
- 证据类型：interaction

### AC-02：碰撞导致游戏结束并显示最终得分

- 验收条件：蛇头碰到边界或自身时游戏结束，并显示最终得分。
- 入口类型：用户界面
- 验证动作：控制蛇朝边界移动，使蛇头撞到边界（或绕行后使蛇头撞到自身）。
- 预期结果：游戏停止移动，界面显示游戏结束与最终得分。
- 证据类型：interaction

### AC-03：游戏结束后可重新开始

- 验收条件：游戏结束后，玩家可启动一局新的游戏，新游戏初始为短蛇、零分。
- 入口类型：用户界面
- 验证动作：在游戏结束状态下触发重新开始操作。
- 预期结果：进入新的游戏局面，蛇恢复初始长度、分数归零，可继续方向控制与移动。
- 证据类型：interaction
