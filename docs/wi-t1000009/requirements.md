# 教师管理系统需求文档

## 1. 目标

构建一个教师管理系统，支持对教师信息的增加、删除、修改和查询操作。

## 2. 教师信息字段

每条教师记录包含以下字段：

| 字段 | 说明 |
|------|------|
| 教师名称 | 教师的姓名 |
| 教授课程 | 该教师所教授的课程 |
| 年级 | 教授课程对应的年级 |
| 手机 | 教师的手机号码 |
| 邮箱 | 教师的电子邮箱 |

> 字段的格式校验规则（如手机号位数、邮箱格式）用户未明确规定，保持未规定，不作为当前基线的正式验收项。

## 3. 核心行为

### 3.1 新增教师

- 用户可填写教师名称、教授课程、年级、手机、邮箱字段并提交保存。
- 保存成功后，该教师记录可通过查询行为读取到。

### 3.2 查询教师

- 用户可查看已保存的教师记录列表。
- 列表中每条记录展示上述五个字段的信息。

### 3.3 修改教师

- 用户可选择一条已有教师记录，修改其任意字段后保存。
- 保存成功后，再次查询该记录可读取到更新后的内容。

### 3.4 删除教师

- 用户可选择一条已有教师记录并执行删除。
- 删除成功后，该记录不再出现在查询列表中。

## 4. 验收场景

### AC-01：用户可新增教师并读取到该记录

- 验收条件：填写全部字段并保存后，该教师记录可通过查询行为读取到。
- 入口类型：用户界面
- 验证动作：在新增入口填写教师名称、教授课程、年级、手机、邮箱，提交保存。
- 预期结果：保存成功后，通过查询可读取到包含上述填写内容的教师记录。
- 证据类型：interaction, session-persistence

### AC-02：用户可查看教师列表

- 验收条件：已保存的教师记录在列表中展示全部五个字段信息。
- 入口类型：用户界面
- 验证动作：进入教师列表/查询入口，查看已保存的教师记录。
- 预期结果：列表中每条教师记录均展示教师名称、教授课程、年级、手机、邮箱五个字段的内容。
- 证据类型：runtime-render

### AC-03：用户可修改教师记录并读取到更新内容

- 验收条件：修改已有教师记录的任意字段并保存后，再次查询可读取到更新后的值。
- 入口类型：用户界面
- 验证动作：选择一条已有教师记录，修改至少一个字段的值，提交保存。
- 预期结果：保存成功后，通过查询该记录可读取到修改后的字段内容，未修改字段保持原值。
- 证据类型：interaction, session-persistence

### AC-04：用户可删除教师记录且该记录不再可见

- 验收条件：删除一条教师记录后，该记录不再出现在查询列表中。
- 入口类型：用户界面
- 验证动作：选择一条已有教师记录，执行删除操作。
- 预期结果：删除成功后，通过查询不再能读取到该教师记录，其余未删除记录不受影响。
- 证据类型：interaction, session-persistence
