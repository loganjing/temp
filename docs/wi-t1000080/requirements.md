# 工单系统需求文档

> Work Item: wi-t1000080 | 编号: T1000080 | 项目: JLGSpace-88

## 1. 产品目标

构建一个面向多公司的工单管理系统，支持工单从创建、分配、处理到完成的全生命周期管理，覆盖工单分配自动化、协作转派、处理追溯、满意度评价和运营统计分析等核心能力。

## 2. 角色与权限边界

| 角色 | 说明 | 来源 |
|------|------|------|
| 提交人 | 创建工单的用户，可在工单完成后进行满意度评价 | 用户明确提出 |
| 处理人 | 业务组成员，接收并处理分配到本组的工单，可转派工单 | 用户明确提出 |
| 管理员 | 管理公司下的业务组及其成员、分类规则配置 | 用户明确提出（业务组管理操作方） |

- 工单按公司隔离：用户只能看到所属公司范围内的工单和数据。（用户明确提出）
- 角色、权限模型的具体实现方案未规定。

- 记录工单相关操作日志。（用户明确提出）
- 涵盖工单生命周期中的关键操作，包括但不限于创建、分配、转派、处理完成、取消等。

## 4. 工单生命周期

```
创建 → 待分配 → 待处理 → 完成
  ↓               ↓
 取消           取消
```

| 状态 | 说明 | 来源 |
|------|------|------|
| 创建 | 工单刚创建的初始状态 | 用户明确提出 |
| 待分配 | 工单已提交，等待分配到业务组 | 用户明确提出 |
| 待处理 | 工单已分配到业务组/处理人，等待处理 | 用户明确提出 |
| 完成 | 工单处理完毕 | 用户明确提出 |
| 取消 | 工单被取消 | 用户明确提出 |

- 状态流转规则（用户明确提出）：
  - `创建` → `待分配`：工单提交后进入待分配
  - `待分配` → `待处理`：通过自动分类规则或手动分配到业务组后进入待处理
  - `待处理` → `完成`：处理人完成处理
  - `待分配` / `待处理` → `取消`：工单可被取消
- 工单转派（用户明确提出）：在待处理状态下，当前处理人可将工单转派给其他业务组或处理人，转派后工单仍处于待处理状态。

## 5. 功能需求

### 5.1 工单管理

- **创建工单**：提交人填写主题、描述、分类，系统自动记录工单ID、提交人信息（姓名、邮箱、公司、部门）和创建时间，设置SLA优先级（P0-P4）。
- **工单回复**：工单详情页支持多轮回复，每条回复记录回复人和回复时间。
- **公司隔离**：用户只能查看和操作所属公司范围内的工单。

### 5.2 工单分配

- **业务组管理**：管理员可为公司创建多个业务组，并为每个业务组添加/管理成员。
- **分类自动分配**：管理员可配置分类与业务组的映射规则；工单进入待分配状态时，系统根据工单分类自动匹配规则，将工单分配到对应业务组，状态转为待处理。
- **手动分配**：当无匹配规则或需人工干预时，支持手动将工单分配到业务组。（推荐基线：闭合"待分配→待处理"流程的必要兜底）

### 5.3 工单协作

- **工单转派**：处理人可将待处理工单转派给其他业务组或处理人。转派记录操作人、转派目标和转派时间。

### 5.4 工单处理

- **提交人信息查看**：处理工单时，可查看提交人的完整信息，包括姓名、公司、部门和历史工单列表。
- **处理记录**：工单完成时记录处理人、处理时间。
- **邮件通知**：工单完成后，系统向提交人邮箱发送完成通知邮件。

### 5.5 用户评价

- **满意度评价**：工单完成后，提交人可对工单处理结果进行满意度评价。

### 5.6 统计分析

- **工单分布统计**：支持按公司、部门维度统计工单分布。
- **运营仪表盘**：展示工单量、平均响应时间、满意度、热点问题等运营指标。

### 5.7 工单工作台

- **待处理列表**：查看待处理工单列表。
- **筛选**：支持按公司维度筛选。
- **搜索**：支持关键词搜索。
- **排序**：支持列表排序。

### 5.8 操作日志

- 记录工单全生命周期的关键操作日志，包括创建、分配、转派、处理完成、取消等。
- 日志记录操作人、操作类型和操作时间。

## 6. 验收场景

### AC-01：提交人可创建工单并包含完整信息

- 验收条件：提交人创建工单后，工单包含ID、主题、描述、分类、提交人信息（含邮箱）、创建时间、SLA优先级，初始状态为创建/待分配，且工单关联到提交人所属公司。
- 入口类型：用户界面
- 验证动作：提交人在工单创建页面填写主题、描述、分类和优先级后提交工单。
- 预期结果：系统生成带唯一ID的工单，记录提交人信息（姓名、邮箱、公司、部门）和创建时间，状态为创建/待分配，工单关联到提交人所属公司。
- 证据类型：interaction, runtime-render

### AC-02：工单支持多轮回复并记录回复人和时间

- 验收条件：工单详情页支持多轮回复，每条回复显示回复人和回复时间。
- 入口类型：用户界面
- 验证动作：在工单详情页多次添加回复。
- 预期结果：每条回复记录并显示回复人信息和回复时间，回复按时间顺序排列。
- 证据类型：interaction, runtime-render

### AC-03：工单按公司隔离

- 验收条件：用户只能查看和操作所属公司范围内的工单，不可看到其他公司的工单。
- 入口类型：用户界面
- 验证动作：分别以不同公司的用户登录，查看工单列表和工作台。
- 预期结果：每个用户只能看到本公司的工单，其他公司工单不可见。
- 证据类型：authorization, runtime-render

### AC-04：工单生命周期状态流转正确

- 验收条件：工单状态按"创建→待分配→待处理→完成"流转，且支持从待分配/待处理状态取消工单。
- 入口类型：用户界面
- 验证动作：创建工单后触发分配使工单进入待处理，处理人完成处理使工单进入完成状态；另对待分配或待处理工单执行取消操作。
- 预期结果：工单状态依次流转至待分配→待处理→完成；取消操作使工单状态变为取消；不可从完成或取消状态再流转。
- 证据类型：interaction, runtime-render

### AC-05：管理员可管理公司业务组及成员

- 验收条件：管理员可为公司创建多个业务组，并为每个业务组添加/管理成员。
- 入口类型：用户界面
- 验证动作：管理员创建业务组并添加成员，查看业务组成员列表。
- 预期结果：业务组创建成功并关联到公司，成员可被添加和查看，支持多个业务组共存。
- 证据类型：interaction, runtime-render

### AC-06：工单按分类自动分配到业务组

- 验收条件：配置分类与业务组的映射规则后，新工单进入待分配状态时系统根据分类自动分配到对应业务组，状态转为待处理。
- 入口类型：用户界面
- 验证动作：管理员配置某分类→业务组的分配规则，提交人创建该分类的工单。
- 预期结果：工单自动分配到规则指定的业务组，状态从待分配变为待处理。
- 证据类型：interaction, runtime-render

### AC-07：处理人可转派工单

- 验收条件：处理人可将待处理工单转派给其他业务组或处理人，转派后工单仍为待处理状态，转派操作被记录。
- 入口类型：用户界面
- 验证动作：处理人在待处理工单详情页执行转派操作，选择目标业务组或处理人。
- 预期结果：工单转派到目标对象，状态保持待处理，转派操作记录在日志中。
- 证据类型：interaction, runtime-render

### AC-08：处理工单时可查看提交人完整信息及历史工单

- 验收条件：处理人在处理工单时，可查看提交人的完整信息，包括姓名、公司、部门和该提交人的历史工单列表。
- 入口类型：用户界面
- 验证动作：处理人打开待处理工单详情，查看提交人信息区域。
- 预期结果：显示提交人姓名、公司、部门信息，以及该提交人的历史工单列表。
- 证据类型：runtime-render

### AC-09：工单完成时记录处理信息并发送邮件通知

- 验收条件：工单完成时记录处理人和处理时间，系统向提交人邮箱发送完成通知邮件。
- 入口类型：用户界面
- 验证动作：处理人对待处理工单执行完成操作。
- 预期结果：工单状态变为完成，记录处理人和处理时间，提交人邮箱收到完成通知邮件。
- 证据类型：interaction, runtime-render

### AC-10：提交人可对已完成工单进行满意度评价

- 验收条件：工单完成后，提交人可对该工单进行满意度评价。
- 入口类型：用户界面
- 验证动作：提交人在已完成的工单详情页提交满意度评价。
- 预期结果：评价成功保存并关联到该工单，评价结果可在工单详情中查看。
- 证据类型：interaction, runtime-render

### AC-11：支持按公司和部门维度统计工单分布

- 验收条件：统计功能支持按公司和部门维度展示工单分布。
- 入口类型：用户界面
- 验证动作：进入统计页面，分别按公司维度和部门维度查看工单分布。
- 预期结果：正确展示各公司、各部门的工单数量分布。
- 证据类型：runtime-render

### AC-12：运营仪表盘展示工单量、平均响应时间、满意度和热点问题

- 验收条件：统计分析仪表盘展示工单量、平均响应时间、满意度评分和热点问题分类等运营指标。
- 入口类型：用户界面
- 验证动作：进入运营仪表盘页面。
- 预期结果：仪表盘展示工单总量、平均响应时间、满意度指标和热点问题（按分类统计的高频问题），数据与实际工单数据一致。
- 证据类型：runtime-render

### AC-13：工单工作台支持筛选、搜索和排序

- 验收条件：工单工作台展示待处理工单列表，支持按公司筛选、关键词搜索和列表排序。
- 入口类型：用户界面
- 验证动作：在工作台使用公司筛选条件、输入关键词搜索、点击列表字段排序。
- 预期结果：列表按筛选条件、搜索关键词和排序方式正确更新展示结果。
- 证据类型：interaction, runtime-render

### AC-14：工单关键操作记录日志

- 验收条件：工单的创建、分配、转派、处理完成、取消等关键操作被记录在操作日志中，日志包含操作人、操作类型和操作时间。
- 入口类型：用户界面
- 验证动作：执行工单创建、分配、转派、完成或取消操作后，查看工单的操作日志。
- 预期结果：日志中包含对应操作记录，每条记录显示操作人、操作类型和操作时间。
- 证据类型：runtime-render
