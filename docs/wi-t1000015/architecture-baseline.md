# 架构基线：实时时钟页面

## 需求基线

本文档基于已批准的需求基线 `docs/wi-t1000015/requirements.md`（SHA-256: `10dc3d6a5211ec9c4911259446266e1f93975a8b76abfce6896ab9055c1eb2ac`）。需求核心为：在页面中实时显示当前时、分、秒（HH:MM:SS），用户无需手动刷新即可看到最新时间。

## 应用类型

**简单前端（simple-frontend）** — 单页面纯客户端应用，不涉及服务端权威数据、认证、后台任务、外部服务集成或跨用户/设备共享。

## 页面与交互范围

- 单一页面，居中展示当前时间，格式 `HH:MM:SS`。
- 页面加载后立即显示当前时间，并通过 `setInterval`（1 秒间隔）驱动每秒更新。
- 无路由、无多页面导航、无用户输入交互。

## 浏览器状态与数据归属

- 本应用无可持久化的业务数据。时间值来自浏览器原生 `Date` API（`new Date()`），仅存在于当前渲染周期，不写入 `localStorage` 或任何持久存储。
- 不涉及跨浏览器、跨设备或跨用户的数据同步。

## 实现入口

- 技术栈：React + Vite SPA。
- 项目入口：`index.html` → `src/main.jsx` → `src/App.jsx`。
- `App` 组件内使用 `useState` 保存当前时间字符串，`useEffect` 中启动 `setInterval` 每秒更新状态，卸载时清除定时器。
- 时间格式化：使用 `Date.prototype.toLocaleTimeString` 或手动 `padStart` 拼接 `HH:MM:SS`。

## 运行方式

- 开发模式：`npm run dev`（Vite 开发服务器），浏览器访问本地开发地址即可。
- 构建产物：`npm run build` 输出到 `dist/`，可通过静态服务器部署。

## 边界说明

- 不引入服务/API、数据库、认证、后台任务、外部集成或同步层。
- 时间精度依赖客户端系统时钟，不与任何外部时间源对时。
