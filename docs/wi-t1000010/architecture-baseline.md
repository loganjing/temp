## 需求引用

基于已批准的需求基线 `docs/wi-t1000010/requirements.md`（SHA-256: `33264e1b02758b7a6170b3b0832dae1b787008cb9975318d8e978075916fde37`）。

## 页面与交互范围

单一页面，打开后居中展示当前时、分、秒（格式 `HH:MM:SS`）。页面加载即显示时间，随后每秒自动更新，用户无需手动刷新。

交互范围仅限于浏览：打开页面 → 看到时间 → 时间逐秒变化。无表单输入、无路由跳转、无用户操作面板。

## 浏览器状态与数据归属

- 时间数据来源：浏览器内置 `Date` API，即用户设备的本地系统时钟。
- 运行状态：页面组件内部维护一个 `currentTime` 状态，通过 `setInterval`（1 秒间隔）驱动更新。不涉及 `localStorage` 或其他持久化——需求仅要求页面打开期间实时显示，刷新或重开后页面会重新获取当前时间。
- 数据不会跨浏览器、设备或用户共享，也不涉及服务端权威数据。

## 技术选型

| 方面 | 选型 | 理由 |
|------|------|------|
| 框架 | React 18 + Vite | 新建 SPA，Vite 提供快速开发服务器与构建 |
| 语言 | TypeScript | 类型安全，符合项目惯例 |
| 样式 | CSS（单文件） | 单页面场景无需 CSS 框架，保持轻量 |

## 实现入口

- 应用入口：`src/main.tsx` 挂载 React 根组件到 `index.html` 的 `#root` 元素。
- 页面组件：`src/Clock.tsx`——负责获取时间、启动定时器、渲染 `HH:MM:SS`。
  - 组件挂载时通过 `useEffect` 初始化 `setInterval`（1000ms），每 tick 调用 `new Date()` 获取当前时间并更新状态。
  - 组件卸载时清理定时器，防止内存泄漏。
- 格式化：将 `Date` 的 `getHours()`、`getMinutes()`、`getSeconds()` 结果补零至两位，拼接为 `HH:MM:SS`。

## 运行方式

- 开发：Vite 开发服务器，启动命令 `npm run dev`，默认端口 `5173`。
- 构建：`npm run build`，产物输出到 `dist/`，可直接用静态服务器部署。

## 不涉及的能力

本设计不引入服务端 API、数据库、认证/权限、后台任务、外部服务集成或跨设备同步层，与需求基线一致。
