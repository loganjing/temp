# 需求文档：实时时钟页面

## 目标

做一个页面，实时显示当前的时、分、秒。

## 核心行为

- 页面打开后立即显示当前时间（时:分:秒）。
- 时间持续自动更新，用户无需手动刷新即可看到秒数逐秒变化。

## 验收场景

### AC-01：页面打开时显示当前时间

- 验收条件：页面加载后，页面上显示当前时间，格式包含时、分、秒三个部分。
- 入口类型：用户界面
- 验证动作：打开页面，观察页面上显示的时间内容。
- 预期结果：页面显示的时间与系统当前时间一致，且包含时、分、秒。
- 证据类型：runtime-render

### AC-02：时间实时自动更新

- 验收条件：页面保持打开期间，显示的时间随时间推移自动更新，秒数逐秒变化，无需用户手动刷新页面。
- 入口类型：用户界面
- 验证动作：打开页面后保持不动，等待数秒后观察页面上显示的时间。
- 预期结果：页面显示的秒数发生变化，且变化后的时间仍与系统当前时间一致。
- 证据类型：interaction
