## 2. 实现内容

### 2.1 服务端（T01）

- 迁移：`src/server/migrations/sqlite/0002_ticket_domain.sql` 落地契约 6.1 全部 9 张表、4 个索引、6 个固定分类种子，与 userkit/auditkit 随包迁移合入同一 dbkit 序列。
- 启动种子：空库幂等创建公司A/公司B 与 5 个示例账号（公司A 提交人×2 异部门、处理人、公司配置管理员，公司B 提交人），口令 `Ticket#Demo2026!`（可 `SEED_PASSWORD` 覆盖），账户经 userkit API 创建并设置组织档案。
- 组织与权限：契约第 4 节组织/配置接口（分类、业务组与成员、分配规则、用户组织档案、公司用户目录）；服务端计算提交人/处理人/公司配置管理员角色、公司隔离与可见范围。
- 工单领域：契约第 3 节全部接口——创建（单事务按分类自动分配）、列表（可见范围过滤/搜索/排序）、详情、提交人完整信息与历史工单、多轮回复（维护 first_reply_at）、手工分配、转派、完成（记录处理人/时间，事务提交后 emailkit 通知，失败不回滚）、取消、评价（每工单一次）、日志读取；非法状态迁移 409，越权 404。
- 统计：契约第 5 节公司/部门分布与仪表盘聚合（工单量、平均响应时间、满意度、热点问题）。
- 审计：契约第 8 节 10 种事件全部经 auditkit 持久化，邮箱脱敏。
- 邮件：契约第 7 节 SMTP 环境变量接线；未配置 SMTP_HOST 时按 emailkit skipped 语义不发送。

### 2.2 前端（T02）

- 契约层：`src/client/contracts.ts`（契约全量类型）、`src/client/api.ts`（24 个接口 typed 封装）、`labels.ts`（状态/优先级/事件中文映射与时间格式化）。
- 页面：登录（含首账户引导与强制改密）、应用壳（左导航 + 顶栏用户/公司/退出）、工单双栏页（列表/详情协同、创建对话框、多轮回复时间线、按角色呈现回复/分配/转派/完成/取消/评价、提交人信息与历史工单区、操作日志）、工作台（status=pending、公司筛选、搜索、创建时间/优先级排序）、统计仪表盘（公司/部门分布 + 四项指标）、配置（业务组与成员、分配规则、用户组织档案）、既有用户管理页集成。
- 视觉：helpdesk 应用模板、split-master-detail 布局、Modern SaaS 基线（状态色映射工单四状态与 P0-P4）；图标统一 lucide-react，无表情符号图标。
- 交互基线：加载骨架、空数据引导、401/403/404/409/422 错误反馈与成功提示。
