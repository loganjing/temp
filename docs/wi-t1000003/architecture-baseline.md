# 架构基线 — 实时时间显示页面

> 基于 `docs/wi-t1000003/requirements.md`（SHA-256: `0bf100ade9c2823c515e4fe9975ab65f89d35815dd8ea9ff39be54acd28dd3d5`）批准的需求基线编写。本设计不扩展或重新裁剪产品语义。

## 应用类型

`simple-frontend`：纯浏览器单页应用，无服务端、无数据库、无认证、无后台任务、无外部集成。

## 页面与交互范围

- 单页面，打开即显示当前本地系统时间的 `HH:MM:SS`（两位补足），无需登录、参数或任何初始化输入。
- 页面通过 `setInterval` 以 1000ms 间隔刷新显示，确保秒值变化可被观察到；秒值到达 59 后正确进位到分，分到达 59 后进位到时。
- 全程无用户交互；用户只需打开页面即可查看实时时间。
- 不附带日期、时区信息（需求未规定，保持不实现）。

## 浏览器状态与数据归属

- 本应用不持久化任何业务数据。时间来源于浏览器运行环境的 `Date` 对象（本地系统时间），每次刷新时重新读取，不依赖 `localStorage` 或其他存储。
- 无跨设备、跨浏览器或跨用户数据共享。

## 实现入口与运行方式

- 新建 React + Vite SPA。
- 实现入口：`src/App.tsx`，内含一个 React 组件，在 `useEffect` 中启动 `setInterval` 每秒更新 `new Date()` 并渲染 `HH:MM:SS` 字符串。
- 运行方式：Vite 开发服务器，通过 `npm run dev` 启动。
- 构建产物：`npm run build` 输出静态资源，可部署到任意静态托管环境。

## 技术承载边界

- 不虚构服务/API、数据库、认证、后台任务、外部集成或同步层。
- 不生成 `technical-contract.md`、`workspace-bootstrap.json`、ADR 或实现计划。
