# 商场清洁系统需求文档

> 工作项：wi-t1000030

## 1. 目标

为商场清洁管理提供一套覆盖区域配置、定时作业调度、障碍处理、耗材库存提醒和作业质量报告的系统，使清洁主管和一线人员能够高效安排、执行和追踪清洁工作。

## 2. 功能需求

### 2.1 清洁区域配置

- 用户可创建、查看、编辑和删除清洁区域配置。
- 每个清洁区域至少记录：区域名称、位置描述、清洁要求（如频次要求、标准说明）。
- 区域配置创建成功后，可通过查看操作读回已保存的区域信息。
- 用户可查看所有清洁区域的列表。

### 2.2 定时作业

- 用户可基于已配置的清洁区域创建定时清洁作业。
- 每个定时作业至少记录：关联区域、执行人、调度周期（如每日、每周指定日）、起始时间。
- 作业按设定的调度周期自动生成待执行任务实例。
- 用户可查看定时作业列表及其对应的任务实例状态。
- 用户可编辑或停用已创建的定时作业；停用后不再生成新的任务实例。

### 2.3 障碍处理

- 清洁人员在执行作业时可上报障碍，至少记录：关联作业实例、障碍描述、上报时间。
- 障碍状态包含：待处理 → 已处理。
- 主管或指定人员可查看待处理障碍列表，并对障碍进行标记处理，记录处理方式和处理结果。
- 障碍处理完成后，关联作业实例的状态相应更新（如标记为"有障碍-已完成"）。

### 2.4 耗材提醒

- 用户可管理清洁耗材库存，至少记录：耗材名称、当前库存数量、单位、最低提醒阈值。
- 当耗材库存低于设定的最低提醒阈值时，系统生成库存不足提醒。
- 用户可查看当前耗材库存列表和未处理的库存不足提醒。
- 耗材入库或消耗后，库存数量更新，低于阈值时触发提醒，补充后提醒可消除。

### 2.5 作业质量报告

- 用户可生成作业质量报告，可按区域和时间范围筛选。
- 报告内容至少包含：作业完成率、障碍统计（上报数量、处理率）、耗材消耗汇总。
- 用户可查看已生成的报告内容。

## 3. 验收场景

### AC-01：用户可完成清洁区域的创建与查看

- 验收条件：用户能够创建清洁区域配置并成功保存，通过查看操作读回已保存的区域信息。
- 入口类型：用户界面
- 验证动作：用户填写区域名称、位置描述和清洁要求后提交创建。
- 预期结果：区域配置成功保存，在区域列表中可查看该区域的完整信息。
- 证据类型：runtime-render, interaction

### AC-02：用户可创建定时清洁作业并自动生成任务实例

- 验收条件：基于已配置的清洁区域创建定时作业后，系统按调度周期自动生成待执行任务实例，用户可在作业列表查看。
- 入口类型：用户界面
- 验证动作：用户选择清洁区域、执行人、调度周期和起始时间后提交创建定时作业。
- 预期结果：定时作业成功保存并出现在作业列表中；按调度周期到达执行时间后，系统生成对应的待执行任务实例，任务实例状态可在列表中查看。
- 证据类型：runtime-render, interaction, session-persistence

### AC-03：清洁人员可上报障碍并完成处理流程

- 验收条件：清洁人员可在执行作业时上报障碍，主管可查看待处理障碍并标记处理，障碍状态和关联作业实例状态相应更新。
- 入口类型：用户界面
- 验证动作：清洁人员对某作业实例上报障碍（填写障碍描述）；主管在障碍列表中查看该障碍并标记为已处理，填写处理方式。
- 预期结果：障碍状态从"待处理"变为"已处理"；关联作业实例状态更新为"有障碍-已完成"；障碍列表中该障碍不再出现在待处理列表。
- 证据类型：runtime-render, interaction, session-persistence

### AC-04：耗材库存低于阈值时生成提醒且补充后可消除

- 验收条件：当耗材库存数量低于最低提醒阈值时系统生成库存不足提醒，用户补充库存后提醒可消除。
- 入口类型：用户界面
- 验证动作：将某耗材库存数量调整至低于其最低提醒阈值；随后将该耗材库存补充至阈值以上。
- 预期结果：库存低于阈值时，库存不足提醒列表中出现该耗材的提醒；补充至阈值以上后，该提醒可标记消除，不再出现在未处理提醒列表中。
- 证据类型：runtime-render, interaction, session-persistence

### AC-05：用户可按区域和时间范围生成作业质量报告

- 验收条件：用户可按区域和时间范围筛选并生成作业质量报告，报告中包含作业完成率、障碍统计和耗材消耗汇总。
- 入口类型：用户界面
- 验证动作：用户选择区域和时间范围后生成报告。
- 预期结果：报告成功生成并展示，内容包含所选范围内的作业完成率、障碍上报数量与处理率、耗材消耗汇总数据。
- 证据类型：runtime-render, interaction
