# 教师管理系统需求（任务：129-teacher）

## 目标

（用户明确提出）建设一个教师管理系统，对教师信息进行管理，支持对教师记录的增加、删除、修改和查询。管理字段包括：教师名称、教授课程、年级、手机、邮箱。

## 核心行为与规则

### 教师记录字段（用户明确提出）

每条教师记录包含以下字段：

| 字段 | 含义 |
| --- | --- |
| 教师名称 | 教师的姓名 |
| 教授课程 | 该教师所教授的课程 |
| 年级 | 该教师所教授的年级 |
| 手机 | 教师的手机号码 |
| 邮箱 | 教师的电子邮箱 |

字段是否必填、格式校验规则等约束：未规定。

### 管理操作（用户明确提出）

系统通过用户界面提供教师的增删改查操作：

- **新增教师**：录入上述字段信息并保存；保存成功后，可通过查询操作读取到该教师及其字段值。
- **查询教师**：可查看教师记录列表，并查看单个教师的字段信息，显示内容与已保存的数据一致。
- **修改教师**：可对已保存教师的字段进行修改并保存；修改成功后，再次查询该教师时显示更新后的字段值。
- **删除教师**：可删除已保存的教师；删除成功后，查询教师列表时不再出现该教师。

写入结果以读取行为读回为准（新增、修改、删除均以相应的查询结果作为可观察结果）。

### 入口

用户明确以人机操作方式描述增删改查，验收入口为**用户界面**；具体页面布局、产品载体（Web、桌面、移动端等）与设备适配方式未规定。

## 验收场景

### AC-01：用户可通过界面完成教师记录的完整增删改查闭环

- 验收条件：用户在系统界面中依次新增一条教师记录、查询并核对该记录、修改其字段、再次查询核对修改结果、最后删除该记录并确认其不再出现；每一步结果均可通过查询行为观察到。
- 入口类型：用户界面
- 验证动作：
  1. 在系统界面新增教师，依次填写教师名称、教授课程、年级、手机、邮箱字段并保存；
  2. 打开教师列表查看该教师，并查看其字段信息；
  3. 将该教师的手机字段改为新值并保存；
  4. 再次查看该教师信息；
  5. 删除该教师并刷新教师列表。
- 预期结果：
  1. 保存成功后，教师列表中出现该教师；
  2. 查看时，教师名称、教授课程、年级、手机、邮箱五个字段均显示，且与录入值一致；
  3. 修改保存成功；
  4. 该教师的手机字段显示为修改后的新值，其余字段保持不变；
  5. 教师列表中不再出现该教师。
- 证据类型：interaction, runtime-render
