# 130-clock：实时显示当前时分秒的页面

## 目标

做一个页面，实时显示当前（最近的）时分秒：用户打开页面即可看到持续更新的当前时间，无需手动刷新。（用户明确提出）

## 核心行为与规则

- 页面打开后立即显示当前时间，展示内容包含时、分、秒三个部分。（用户明确提出）
- 时间随真实时间推进自动刷新，页面始终显示最新的时分秒，无需用户手动刷新。（用户明确提出）
- 显示精度到秒，页面显示时间与设备真实时间的偏差不超过 1 秒，刷新节奏与秒级精度一致。（推荐基线：将“实时”闭合为可观察的精度结果）
- 时间来源默认采用用户设备本地时间。（推荐基线：保守默认，可由用户调整）
- 未规定事项：小时制式（12/24 小时制）、是否同时显示日期、页面版式与样式细节。

## 验收场景

### AC-01：页面实时显示当前时分秒
- 验收条件：页面打开后，用户无需任何操作即可看到包含时、分、秒的当前时间，且时间随真实时间自动更新，始终为最新的时分秒。
- 入口类型：用户界面
- 验证动作：打开该页面，观察时间显示；连续观察至少 5 秒并跨越至少一次秒位跳变，同时将页面显示时间与设备当前时间对比。
- 预期结果：页面始终显示时、分、秒三个部分；每过一秒自动更新为最新时间，页面无需手动刷新；页面显示时间与设备当前时间偏差不超过 1 秒。
- 证据类型：runtime-render
