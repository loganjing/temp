# 工单系统需求文档

## 1. 目标

构建一个工单管理系统，支持工单从创建到完成的全生命周期管理，包括工单分配、协作转派、处理通知、用户评价、统计分析和工作台等功能。工单按公司隔离，支持 SLA 优先级与分类自动分配。

## 2. 用户角色

| 角色 | 说明 | 来源 |
|------|------|------|
| 提交人 | 创建工单、查看工单进度、接收完成通知、进行满意度评价 | 用户明确提出 |
| 处理人 | 处理工单、回复工单、转派工单 | 用户明确提出 |
| 管理员 | 配置公司业务组及成员、配置分类自动分配规则 | 用户明确提出（工单分配功能点） |

## 3. 核心实体与状态

### 3.1 工单生命周期

```
创建 → 待分配 → 待处理 → 完成
                    ↘ 取消
```

- **创建**：提交人创建工单后初始状态
- **待分配**：工单等待分配到业务组或处理人
- **待处理**：工单已分配，等待处理人处理
- **完成**：工单处理完毕
- **取消**：工单被取消

来源：用户明确提出。

### 3.2 SLA 优先级

支持 P0、P1、P2、P3、P4 五个优先级等级。来源：用户明确提出。

### 3.3 工单核心字段

- 工单ID（系统生成，唯一标识）
- 主题
- 描述
- 分类
- 提交人信息（姓名、邮箱、公司、部门）
- 创建时间
- SLA 优先级（P0-P4）

来源：用户明确提出。

## 4. 模块需求

### 4.1 工单管理

- 工单创建时记录工单ID、主题、描述、分类、提交人信息（含邮箱）和创建时间
- 工单支持多轮回复，每条回复记录回复人和回复时间
- 工单按公司隔离：一个公司的用户只能看到本公司的工单，不能看到其他公司的工单
- 支持设置 SLA 优先级（P0-P4）和问题分类
- 工单状态流转遵循生命周期：创建 → 待分配 → 待处理 → 完成；支持取消

### 4.2 工单分配

- 允许给某个公司增加多个业务组
- 每个业务组可以设置成员
- 允许配置规则：某个公司的工单按照分类自动分配到某个业务组

### 4.3 工单协作

- 支持工单转派操作：将工单从一个处理人/业务组转派到另一个处理人/业务组
- 转派后工单状态保持可继续处理

### 4.4 工单处理

- 在处理工单时可查看提交人的完整信息，包括姓名、公司、部门、历史工单等
- 工单处理完成后，记录处理人和处理时间
- 工单完成时发送邮件通知提交人

### 4.5 用户评价

- 用户收到完成的工单后可进行满意度评价

### 4.6 统计分析

- 支持按公司、部门维度统计工单分布
- 统计与分析仪表盘，展示以下运营指标：
  - 工单量
  - 平均响应时间
  - 满意度
  - 热点问题

### 4.7 工单工作台

- 查看待处理工单列表
- 支持筛选（含按公司维度筛选）、搜索、排序

### 4.8 操作日志

- 记录工单相关操作日志（创建、分配、转派、处理、完成、取消等关键操作）

## 5. 未规定事项

以下事项用户未明确要求，不在当前基线中规定：

- 邮件通知的技术实现方式与邮件服务选型
- RBAC 细粒度权限模型与角色权限矩阵
- 存储方案与数据库选型
- SLA 自动升降级或超时自动处理规则
- 历史工单展示数量上限与排序规则
- 部署方式与运行环境
- 工单取消的权限归属与前置条件
- 响应时间的计算口径（从创建到首次回复，或从分配到完成）

## 6. 验收场景

### AC-01：提交人创建工单并记录完整信息
- 验收条件：提交人创建工单后，系统生成唯一工单ID，并记录主题、描述、分类、提交人信息（含邮箱）和创建时间，工单状态为"创建"或进入"待分配"。
- 入口类型：用户界面
- 验证动作：提交人填写工单主题、描述、分类并提交创建。
- 预期结果：工单创建成功，可查看到工单ID、主题、描述、分类、提交人信息（含邮箱）、创建时间，工单状态正确。
- 证据类型：runtime-render, interaction

### AC-02：工单支持多轮回复
- 验收条件：工单创建后，处理人和提交人可对工单进行多轮回复，每条回复记录回复人和回复时间。
- 入口类型：用户界面
- 验证动作：在工单详情中对工单进行两次以上回复。
- 预期结果：每条回复内容、回复人、回复时间均可查看，回复按时间顺序排列。
- 证据类型：runtime-render, interaction, session-persistence

### AC-03：工单按公司隔离
- 验收条件：一个公司的用户只能查看和操作本公司的工单，不能看到其他公司的工单。
- 入口类型：用户界面
- 验证动作：以A公司用户身份查看工单列表，确认不出现B公司的工单。
- 预期结果：工单列表仅包含当前用户所属公司的工单。
- 证据类型：authorization, session-persistence

### AC-04：设置SLA优先级和问题分类
- 验收条件：创建或编辑工单时可设置SLA优先级（P0-P4）和问题分类，保存后可读回。
- 入口类型：用户界面
- 验证动作：创建工单时选择SLA优先级和分类并保存，查看工单详情。
- 预期结果：工单详情中显示所选优先级和分类，与设置一致。
- 证据类型：runtime-render, interaction, session-persistence

### AC-05：工单状态生命周期流转
- 验收条件：工单状态可按生命周期流转：创建 → 待分配 → 待处理 → 完成，并支持取消。
- 入口类型：用户界面
- 验证动作：创建工单后，依次执行分配、处理、完成操作，并单独验证取消路径。
- 预期结果：每次操作后工单状态正确流转到下一状态；取消操作后工单状态为"取消"。
- 证据类型：runtime-render, interaction, session-persistence

### AC-06：配置公司业务组及成员
- 验收条件：管理员可为某个公司增加多个业务组，每个业务组可设置成员。
- 入口类型：用户界面
- 验证动作：管理员为公司A创建两个业务组，分别为每个业务组添加成员。
- 预期结果：业务组及成员配置成功，可查看到业务组列表和各业务组成员。
- 证据类型：runtime-render, interaction, session-persistence

### AC-07：工单按分类自动分配到业务组
- 验收条件：配置分类自动分配规则后，新建工单按其分类自动分配到对应业务组，工单状态进入"待处理"。
- 入口类型：用户界面
- 验证动作：管理员配置"分类X → 业务组Y"的自动分配规则后，提交人创建分类为X的工单。
- 预期结果：工单自动分配到业务组Y，工单状态为"待处理"，可查看到分配的业务组信息。
- 证据类型：runtime-render, interaction, session-persistence

### AC-08：工单转派
- 验收条件：处理人可将工单转派给其他处理人或业务组，转派后工单保持可继续处理。
- 入口类型：用户界面
- 验证动作：处理人对一个待处理工单执行转派操作，选择目标处理人或业务组。
- 预期结果：工单转派成功，新的处理人或业务组可查看并继续处理该工单。
- 证据类型：runtime-render, interaction, session-persistence

### AC-09：处理工单时查看提交人完整信息
- 验收条件：处理人在处理工单时可查看提交人的完整信息，包括姓名、公司、部门和历史工单。
- 入口类型：用户界面
- 验证动作：处理人打开一个待处理工单，查看提交人信息区域。
- 预期结果：可查看到提交人姓名、公司、部门及历史工单列表。
- 证据类型：runtime-render, session-persistence

### AC-10：工单完成记录处理信息并发送邮件通知
- 验收条件：工单完成后，系统记录处理人和处理时间，并向提交人发送邮件通知。
- 入口类型：用户界面
- 验证动作：处理人将待处理工单标记为完成。
- 预期结果：工单状态变为"完成"，可查看到处理人和处理时间记录；提交人邮箱收到完成通知邮件。
- 证据类型：runtime-render, interaction, session-persistence

### AC-11：用户满意度评价
- 验收条件：用户收到完成的工单后可进行满意度评价，评价结果可查看。
- 入口类型：用户界面
- 验证动作：提交人在已完成的工单上进行满意度评价。
- 预期结果：评价提交成功，工单详情中可查看到满意度评价结果。
- 证据类型：runtime-render, interaction, session-persistence

### AC-12：统计分析与仪表盘
- 验收条件：统计分析支持按公司、部门维度统计工单分布，仪表盘展示工单量、平均响应时间、满意度和热点问题等运营指标。
- 入口类型：用户界面
- 验证动作：进入统计仪表盘页面，按公司维度筛选查看工单分布和各项运营指标。
- 预期结果：仪表盘正确展示工单量、平均响应时间、满意度、热点问题等指标，按公司/部门维度可查看工单分布。
- 证据类型：runtime-render, session-persistence

### AC-13：工单工作台筛选搜索排序
- 验收条件：工单工作台展示待处理工单列表，支持筛选（含按公司维度）、搜索和排序。
- 入口类型：用户界面
- 验证动作：进入工单工作台，使用筛选条件（含公司）、关键词搜索和排序功能操作工单列表。
- 预期结果：工单列表按筛选、搜索和排序条件正确呈现，仅显示符合条件的待处理工单。
- 证据类型：runtime-render, interaction, session-persistence

### AC-14：操作日志记录
- 验收条件：工单的创建、分配、转派、处理、完成、取消等关键操作均有日志记录，可查看。
- 入口类型：用户界面
- 验证动作：执行一系列工单操作（创建、分配、处理等），查看工单的操作日志。
- 预期结果：操作日志中按时间顺序记录每项关键操作，包含操作类型和操作时间。
- 证据类型：runtime-render, session-persistence
