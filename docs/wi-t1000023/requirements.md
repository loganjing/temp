# 需求规格：机器人巡逻告警系统（160-robotwarning）

## 1. 目标

为巡逻机器人提供从路线配置到事件处置的完整告警闭环：支持配置巡逻路线、识别视频中的异常事件、实时推送告警、人工处置告警，并对全流程事件进行留痕，便于追溯和审计。

## 2. 用户旅程

### 2.1 巡逻路线配置与执行

操作人员配置巡逻路线 → 机器人按路线执行巡逻 → 巡逻过程中采集视频 → 系统识别视频事件 → 生成实时告警 → 操作人员处置告警 → 事件及处置过程留痕

### 2.2 告警处置

系统检测到视频事件并生成告警 → 告警实时推送给操作人员 → 操作人员查看告警详情和关联视频 → 操作人员执行处置操作 → 处置结果记录到事件留痕

## 3. 模块需求

### 3.1 巡逻路线配置

- 支持创建、编辑、查看和删除巡逻路线。
- 路线配置至少包含路线名称和巡逻路径点（途经位置序列）。
- 支持查看路线列表和单条路线详情，保存后可通过相应读取行为读回。
- 删除路线时应有确认操作，防止误删（推荐基线）。

### 3.2 视频事件识别

- 系统对巡逻过程中采集的视频进行自动事件识别。
- 识别到的事件应包含事件类型、发生时间、关联路线和位置信息。
- 视频事件识别为系统自动行为，不需要操作人员主动触发。

### 3.3 实时告警

- 视频事件识别结果触发告警，告警应实时推送至操作人员。
- 告警信息至少包含告警时间、事件类型、关联路线/位置和关联视频片段。
- 操作人员能查看当前未处置的告警列表。
- 告警推送应尽量实时；具体延迟阈值未规定。

### 3.4 人工处置

- 操作人员可查看告警详情，包括关联的视频片段。
- 操作人员可对告警执行处置操作，至少包括标记处置结果和填写处置说明。
- 处置完成后，告警状态应更新为已处置。
- 已处置的告警可在历史记录中查看。

### 3.5 事件留痕

- 系统记录从视频事件识别到告警处置的全流程事件链。
- 留痕信息至少包含：视频事件（类型、时间、路线/位置）、关联告警、处置记录（处置人、处置时间、处置结果、处置说明）。
- 留痕记录可查询和查看，支持按时间和事件类型等条件检索。
- 留痕记录不可被修改或删除，保证审计完整性。

## 4. 验收场景

### AC-01：巡逻路线可配置并读回

- 验收条件：操作人员可创建巡逻路线并成功保存，保存后可通过列表和详情读取到已配置的路线信息。
- 入口类型：用户界面
- 验证动作：创建一条包含名称和路径点的巡逻路线，保存后查看路线列表和该路线详情。
- 预期结果：路线列表中显示新创建的路线，详情页展示与创建时一致的名称和路径点信息。
- 证据类型：runtime-render, interaction

### AC-02：视频事件识别结果生成告警

- 验收条件：巡逻过程中系统识别到视频事件后，自动生成对应告警，告警信息包含事件类型、时间、关联路线/位置。
- 入口类型：后台任务
- 验证动作：模拟或触发一次视频事件识别，检查是否生成对应告警记录。
- 预期结果：生成一条告警记录，包含事件类型、发生时间、关联路线和位置信息。

### AC-03：告警实时推送至操作人员

- 验收条件：告警生成后，操作人员能实时收到告警通知，并可在告警列表中查看新告警。
- 入口类型：用户界面
- 验证动作：触发一次告警后，观察操作人员侧的告警通知和未处置告警列表。
- 预期结果：操作人员收到新告警通知，未处置告警列表中出现该告警，信息包含告警时间、事件类型和关联路线/位置。
- 证据类型：runtime-render, interaction

### AC-04：操作人员可处置告警

- 验收条件：操作人员可查看告警详情并执行处置操作，处置后告警状态更新为已处置，处置记录可读回。
- 入口类型：用户界面
- 验证动作：选择一条未处置告警，查看详情，执行处置操作（填写处置结果和说明），保存后查看该告警状态和处置记录。
- 预期结果：告警状态更新为已处置，处置记录包含处置结果和处置说明，可在历史记录中查看。
- 证据类型：runtime-render, interaction, session-persistence

### AC-05：事件全流程留痕可查

- 验收条件：从视频事件识别到告警处置的全流程信息可在事件留痕中查询和查看，且记录不可被修改。
- 入口类型：用户界面
- 验证动作：完成一次从事件识别到告警处置的完整流程后，在事件留痕中按时间和事件类型检索，查看该事件链的完整记录。
- 预期结果：检索到包含视频事件、关联告警和处置记录的完整事件链记录，信息一致且不可被编辑或删除。
- 证据类型：runtime-render, interaction
