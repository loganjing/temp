# k07-clock 架构基线

## 需求基线引用

本设计基于已批准的需求快照 `docs/wi-t1000044/requirements.md`（sha256: `333a3d7e7feb8f624198941081a0152b1b58c2edf8aa34f11dd4379f3cabc0c2`），不扩展或重裁其产品语义。

## 页面与交互范围

- 单页面 React/Vite SPA，页面正中展示当前时间，格式为 `HH:MM:SS`（24 小时制，各部分两位数字）。
- 时间数据来自浏览器原生 `Date` API，使用浏览器本地时区，无服务端参与。
- 页面加载后立即显示当前时间，并以 `setInterval` 每秒（1000ms）刷新一次，确保秒数与系统时间一致。
- 用户无需任何交互即可查看实时时间；无表单、无路由、无多页面切换。

## 浏览器状态与数据归属

- 应用不持久化任何数据，不使用 `localStorage` 或其他客户端存储。
- 时间状态仅在 React 组件内存中通过 `useState` 维持，每次 tick 由 `setInterval` 回调读取 `new Date()` 并更新状态。
- 页面刷新或重新打开后重新从系统时钟读取当前时间，不保留历史状态。
- 数据仅在本浏览器标签页内可用，不跨设备、跨浏览器或跨用户共享。

## 实现入口与运行方式

- 技术栈：React + Vite（TypeScript）。
- 应用入口：`index.html` → `src/main.tsx` → `src/App.tsx`。
- `App.tsx` 内定义时钟组件，使用 `useState` 存储当前时间字符串，`useEffect` 中注册 `setInterval(update, 1000)`，卸载时 `clearInterval`。
- 时间格式化：使用 `Date` 实例的 `getHours()`、`getMinutes()`、`getSeconds()`，以 `String.padStart(2, '0')` 补零，拼接为 `HH:MM:SS`。
- 运行方式：Vite 开发服务器，`npm run dev` 启动本地开发预览；`npm run build` 生成静态产物。

## UI 选型

- 本应用为单一时钟展示页面，不属于管理工作台类别，不采用 Ant Design 等组件库。
- 使用纯 CSS 实现页面样式：居中布局、等宽字体（monospace）展示数字，确保时间数字对齐稳定。
- 视觉风格保持简洁，背景与字体颜色对比清晰，满足可读性即可。

## 验证说明

- AC-01 涉及自动推进的实时时间，属定时更新场景。
- 页面打开后可直接验证：观察显示的 `HH:MM:SS` 与打开时系统时间一致，并在不刷新页面的情况下观察秒数随系统时间推进变化。
- 时间值来源于系统时钟，无需预置状态或固定结果；验证通过人眼或自动化脚本比对显示值与 `new Date()` 即可。
- 无需额外测试控制入口，正常运行即为可验证状态。
