# 166-clock 架构基线

## 需求基线引用

本文基于已批准的需求快照 `docs/wi-t1000044/requirements.md`（sha256: `sha256:91d57b583562c2ce007fd676fd895d6527879f59669484ce55542149ff4b8623`）进行设计，不扩展或重裁产品语义。

## 应用类型

纯前端单页应用（simple-frontend）。时间取自浏览器所在设备的本地系统时钟，由页面自行渲染并自动更新，不涉及服务端权威数据、数据库、认证、后台任务、外部服务或跨用户/设备共享。

## 页面与交互范围

- 单页面，打开后即显示当前本地时间，格式为 `HH:MM:SS`，时、分、秒均两位前导补零。
- 时间随系统时钟实时自动更新，无需用户手动刷新或任何交互。
- 页面以可见文字展示时间，无输入、无按钮、无其他交互元素。
- 唯一验收入口为用户界面，证据类型为 `runtime-render`（对应 AC-01）。

## 浏览器状态与数据归属

- 应用不持久化任何业务数据；时间值每次由 `Date` 对象读取设备本地时钟得到，属于瞬时运行状态。
- 无 `localStorage`、`sessionStorage` 或其他存储写入；刷新或重开页面后重新读取系统时钟即可，不存在数据保留或跨浏览器/设备共享语义。

## 实现入口与运行方式

- 采用 React + Vite SPA。
- 时间更新机制：组件挂载后启动定时器（`setInterval`，周期 1000ms），每秒读取 `new Date()` 并重渲染；组件卸载时清理定时器。
- 时间格式化：使用 `String.prototype.padStart(2, '0')` 对时、分、秒做两位补零，拼接为 `HH:MM:SS`。
- 新建应用使用 Vite 开发服务器运行：`npm run dev`。
- 页面无路由、无第三方依赖、无外部 API 调用。
