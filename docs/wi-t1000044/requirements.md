# 166-clock 需求

## 目标

做一个页面，实时显示当前的时分秒。

## 核心行为

- 页面打开后显示当前本地时间，格式为"时:分:秒"（HH:MM:SS），不足两位时前导补零。
- 时间随系统时钟实时自动更新，无需用户手动刷新。
- 页面以可见文字展示时间，不依赖用户交互即可持续更新。

## 验收场景

### AC-01：页面实时显示当前时分秒
- 验收条件：页面打开后显示当前本地时间（时、分、秒），且时间随系统时钟自动更新。
- 入口类型：用户界面
- 验证动作：打开页面，观察显示的时间是否与当前本地时间一致；观察显示的时间是否自动随系统时钟变化。
- 预期结果：页面以 HH:MM:SS 格式显示当前本地时间，且无需手动刷新即可实时更新。
- 证据类型：runtime-render
