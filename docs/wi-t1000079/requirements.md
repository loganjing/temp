# 工单系统需求文档

## 1. 概述

构建一个工单系统，支持工单的创建、分配、处理、协作、评价和统计分析全生命周期管理。工单按公司隔离，支持 SLA 优先级（P0-P4）和问题分类，具备业务组自动分配、工单转派、邮件通知、满意度评价、运营仪表盘和工单工作台等能力。

## 2. 用户角色

以下角色由用户描述的操作行为推断，非额外设定：

| 角色 | 说明 |
|------|------|
| 工单提交人 | 创建工单、回复工单、接收完成通知、进行满意度评价 |
| 工单处理人 | 处理分配到自身/所属业务组的工单、回复工单、记录处理信息、转派工单 |
| 业务组管理员 | 管理所属公司的业务组成员、配置分类自动分配规则 |

## 3. 核心实体与生命周期

### 3.1 工单核心字段

用户明确提出工单需包含以下字段：

| 字段 | 说明 |
|------|------|
| 工单ID | 唯一标识 |
| 主题 | 工单标题 |
| 描述 | 工单详细内容 |
| 分类 | 问题分类 |
| 提交人信息 | 含姓名、邮箱 |
| 创建时间 | 工单创建的时间戳 |
| SLA优先级 | P0-P4 五级优先级 |
| 所属公司 | 工单归属的公司，用于数据隔离 |

### 3.2 工单生命周期

用户明确指定以下状态：

```
创建 → 待分配 → 待处理 → 完成
                ↓
              取消
```

| 状态 | 说明 |
|------|------|
| 创建 | 工单刚创建，尚未分配 |
| 待分配 | 工单等待分配到业务组或处理人 |
| 待处理 | 工单已分配，等待或正在处理中 |
| 完成 | 工单处理完成，触发邮件通知 |
| 取消 | 工单被取消，终止处理流程 |

### 3.3 工单回复

工单支持多轮回复，每条回复记录：
- 回复人
- 回复时间
- 回复内容

## 4. 模块需求

### 4.1 工单管理

- 用户可创建工单，填写主题、描述、分类、SLA优先级（P0-P4），系统自动记录工单ID、提交人信息（含邮箱）和创建时间
- 工单创建后进入"创建"状态，随后流转至"待分配"
- 工单支持多轮回复，每条回复记录回复人、回复时间和回复内容
- 工单按公司隔离：用户只能查看和操作所属公司范围内的工单，不能跨公司访问
- 支持设置 SLA 优先级（P0、P1、P2、P3、P4）和问题分类

### 4.2 工单分配

#### 4.2.1 业务组管理

- 允许给某个公司增加多个业务组
- 每个业务组可以设置成员（处理人）

#### 4.2.2 分类自动分配

- 允许为某个公司的工单配置分类与业务组的映射规则
- 工单创建后，系统根据工单分类自动匹配规则，将工单分配到对应的业务组
- 分配后工单状态从"待分配"流转至"待处理"

### 4.3 工单协作

- 支持工单转派操作：处理人可将工单转派给其他处理人或业务组
- 转派后工单仍保持"待处理"状态，接收方成为新的处理人/处理组

### 4.4 工单处理

#### 4.4.1 提交人信息查看

- 在处理工单时，处理人可查看提交人的完整信息，包括：
  - 姓名
  - 公司
  - 部门
  - 历史工单列表

#### 4.4.2 处理记录与完成通知

- 工单处理后，记录处理人和处理时间
- 工单标记为"完成"状态时，系统向提交人邮箱发送邮件通知

### 4.5 用户评价

- 工单完成后，提交人收到通知并可对工单进行满意度评价
- 满意度评价结果记录在工单上

### 4.6 统计分析

#### 4.6.1 工单分布统计

- 支持按公司维度统计工单分布
- 支持按部门维度统计工单分布

#### 4.6.2 运营仪表盘

- 统计与分析仪表盘展示以下运营指标：
  - 工单量
  - 平均响应时间
  - 满意度
  - 热点问题

### 4.7 工单工作台

- 查看待处理工单列表
- 支持筛选（含按公司维度筛选）
- 支持搜索
- 支持排序

### 4.8 操作日志

- 记录工单相关操作日志，覆盖工单生命周期中的关键操作（创建、分配、转派、处理、完成、取消）

## 5. 验收场景

### AC-01：工单创建与基础管理

- 验收条件：用户可创建工单，填写主题、描述、分类和 SLA 优先级（P0-P4），系统自动生成工单ID、记录提交人信息（含邮箱）和创建时间，工单进入初始生命周期状态。
- 入口类型：用户界面
- 验证动作：提交人创建一张工单，填写主题、描述、选择分类和优先级。
- 预期结果：工单创建成功，可查看到工单ID、提交人信息（含邮箱）、创建时间，状态为初始状态（创建/待分配）。
- 证据类型：runtime-render, interaction

### AC-02：工单多轮回复

- 验收条件：工单支持多轮回复，每条回复记录回复人、回复时间和回复内容，回复按时间顺序展示。
- 入口类型：用户界面
- 验证动作：在已创建的工单上，不同用户依次添加多条回复。
- 预期结果：所有回复均成功保存，每条回复显示回复人、回复时间和内容，按时间顺序排列。
- 证据类型：runtime-render, interaction, session-persistence

### AC-03：工单公司隔离

- 验收条件：工单按公司隔离，用户只能查看和操作所属公司范围内的工单，不能访问其他公司的工单。
- 入口类型：用户界面
- 验证动作：使用 A 公司用户创建工单后，切换为 B 公司用户查看工单列表和详情。
- 预期结果：B 公司用户无法看到 A 公司的工单，工单列表和详情均仅展示当前用户所属公司的工单。
- 证据类型：runtime-render, authorization

### AC-04：SLA 优先级与问题分类

- 验收条件：工单支持设置 SLA 优先级（P0-P4）和问题分类，且可在工单列表和工作台中按优先级和分类筛选。
- 入口类型：用户界面
- 验证动作：创建多张不同优先级和分类的工单，在工作台中按优先级或分类筛选。
- 预期结果：筛选结果仅展示匹配的工单，优先级涵盖 P0-P4 五级，分类可正确区分。
- 证据类型：runtime-render, interaction

### AC-05：业务组管理与分类自动分配

- 验收条件：可为某个公司增加多个业务组并设置成员，配置分类与业务组的映射规则后，新创建的工单按分类自动分配到对应业务组，工单状态从"待分配"流转至"待处理"。
- 入口类型：用户界面
- 验证动作：为某公司创建业务组并添加成员，配置分类→业务组映射规则，然后创建该分类的工单。
- 预期结果：工单创建后自动匹配分类规则并分配到对应业务组，工单状态变为"待处理"，业务组成员可看到该工单。
- 证据类型：runtime-render, interaction, session-persistence

### AC-06：工单转派

- 验收条件：处理人可将工单转派给其他处理人或业务组，转派后接收方成为新的处理人/处理组，工单保持"待处理"状态。
- 入口类型：用户界面
- 验证动作：处理人在一张"待处理"工单上执行转派操作，选择目标处理人或业务组。
- 预期结果：工单转派成功，新处理人/业务组成员可看到该工单，原处理人不再作为当前处理人，工单状态仍为"待处理"。
- 证据类型：runtime-render, interaction, session-persistence

### AC-07：工单处理与完成邮件通知

- 验收条件：处理人在处理工单时可查看提交人完整信息（姓名、公司、部门、历史工单），工单完成后记录处理人和处理时间，系统向提交人邮箱发送完成通知邮件。
- 入口类型：用户界面
- 验证动作：处理人打开一张"待处理"工单，查看提交人完整信息，处理后将工单标记为"完成"。
- 预期结果：处理人可查看到提交人的姓名、公司、部门和历史工单列表；工单状态变为"完成"，记录处理人和处理时间；提交人邮箱收到完成通知邮件。
- 证据类型：runtime-render, interaction, session-persistence

### AC-08：用户满意度评价

- 验收条件：工单完成后，提交人可对工单进行满意度评价，评价结果记录在工单上。
- 入口类型：用户界面
- 验证动作：提交人在已完成的工单上进行满意度评价。
- 预期结果：评价成功提交并记录在工单上，可查看评价结果。
- 证据类型：runtime-render, interaction, session-persistence

### AC-09：工单分布统计

- 验收条件：支持按公司和部门维度统计工单分布，统计结果正确反映各公司/部门的工单数量。
- 入口类型：用户界面
- 验证动作：在统计分析页面查看按公司维度和部门维度的工单分布。
- 预期结果：统计页面展示各公司和各部门的工单分布数据，数据与实际工单一致。
- 证据类型：runtime-render

### AC-10：运营仪表盘

- 验收条件：统计与分析仪表盘展示工单量、平均响应时间、满意度和热点问题等运营指标。
- 入口类型：用户界面
- 验证动作：打开运营仪表盘页面，查看各项运营指标。
- 预期结果：仪表盘展示工单量、平均响应时间、满意度评分和热点问题分类等指标，数据基于实际工单数据计算。
- 证据类型：runtime-render

### AC-11：工单工作台

- 验收条件：工单工作台展示待处理工单列表，支持按公司维度筛选、关键词搜索和字段排序。
- 入口类型：用户界面
- 验证动作：打开工单工作台，使用公司筛选、关键词搜索和排序功能。
- 预期结果：工作台列表展示待处理工单，筛选、搜索和排序结果正确反映操作条件。
- 证据类型：runtime-render, interaction

### AC-12：工单取消

- 验收条件：工单可被取消，取消后状态变为"取消"，终止处理流程。
- 入口类型：用户界面
- 验证动作：对一张非完成状态的工单执行取消操作。
- 预期结果：工单状态变为"取消"，不再进入处理流程。
- 证据类型：runtime-render, interaction, session-persistence

### AC-13：操作日志记录

- 验收条件：系统记录工单生命周期中的关键操作日志（创建、分配、转派、处理、完成、取消），日志可查看。
- 入口类型：用户界面
- 验证动作：执行工单创建、分配、转派、完成等操作后，查看工单的操作日志。
- 预期结果：操作日志记录了已执行的关键操作，包含操作类型和操作时间，可按工单查看。
- 证据类型：runtime-render, session-persistence
