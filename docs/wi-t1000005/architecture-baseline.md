# 架构基线 — 专注时段记录系统（143-timeline）

> 需求基线：`docs/wi-t1000005/requirements.md`（sha256:7c04bfbda6ff8af6640982c3b6df166319986ba3c3e08557bd61887ab7f90d51）

## 1. 路线与数据归属

- **路线**：simple-frontend（精简前端单页应用）。
- **数据归属**：所有专注记录、累计时长、热力图数据均存储于浏览器 `localStorage`，与当前浏览器配置文件绑定。刷新或重新打开页面后数据仍可读取；不跨浏览器、不跨设备、不跨用户共享。
- **无服务端**：不涉及服务端 API、数据库、认证/权限、后台任务、外部服务集成或同步层。

## 2. 页面与交互范围

单页面（SPA）承载全部功能，页面内自上而下分为三个区域：

1. **顶部 — 累计专注时长**：显示当日所有已完成番茄钟的专注时长之和，新记录产生后随即更新。
2. **中部 — 番茄钟**：内置倒计时，25 分钟专注 + 5 分钟休息自动轮转；提供开始、暂停/继续、重置当前时段控制。
3. **底部 — 当日热力图**：按小时划分全天时段，颜色深浅对应该时段已完成专注时长；无记录时显示空状态。

完成一个完整番茄钟（25 分钟专注自然结束）后，自动向当日列表写入一条记录并刷新累计时长与热力图。未完整完成的专注时段不产生记录。

## 3. 状态与存储设计

| 存储键 | 内容 | 生命周期 |
|---|---|---|
| `focus_records_{date}` | 当日已完成番茄钟记录数组（开始时间、结束时间、时长） | 以本地自然日为键；跨过本地零点后面向新的一天 |

- 累计专注时长与热力图均由当日记录数组派生计算，不单独持久化。
- 番茄钟运行时状态（当前阶段、剩余时间、运行/暂停）仅存于内存，不持久化；页面刷新后回到专注待开始状态。
- 当日日期按用户所在地本地自然日判定。

## 4. 实现入口与运行方式

- **技术栈**：React + Vite SPA（新应用）。
- **入口**：`src/main.tsx` 挂载根组件 `src/App.tsx`。
- **运行**：`npm run dev` 启动 Vite 开发服务器，浏览器访问开发服务器地址即可使用。
- **构建产物**：`npm run build` 生成静态资源，可部署至任意静态托管。

## 5. 校验边界

- 数据读写仅通过 `localStorage`，读写边界由应用自身管理，无外部信任边界。
- 不涉及网络请求、认证校验或跨域问题。
- 验收范围限于浏览器端 runtime-render、interaction 与 session-persistence。
