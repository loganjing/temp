# 架构基线：实时时钟页面

> 引用需求基线：`docs/wi-t1000013/requirements.md`（SHA-256: `6a983beb65a455293c7b6f574e7435d95d45b09166c700e67fbf8abc390089cb`）

## 应用类型

`simple-frontend` — 纯前端 SPA，无需服务端、数据库、认证或外部集成。

## 页面与交互范围

- 单一页面，打开后居中显示当前时间，格式 `HH:MM:SS`（24 小时制，两位补零）。
- 时间每秒自动更新，用户无需任何操作。
- 无其他功能模块、无用户输入、无导航。

## 浏览器状态与数据归属

- 应用不持久化任何业务数据。时间值直接来自浏览器运行时 `Date` 对象，仅存在于当前页面会话的内存中。
- 不使用 `localStorage` 或其他存储——无数据需要在刷新后保留。
- 不与其他浏览器、设备或用户共享任何数据。

## 技术选型

| 维度 | 选择 |
|------|------|
| 框架 | React 18 + Vite（SPA） |
| 语言 | JavaScript |
| 样式 | CSS（内联样式表，居中布局） |
| 时间源 | 浏览器 `Date` 对象 |
| 定时机制 | `setInterval` 每 1000ms 更新 |

## 实现入口

- 新建 React/Vite SPA 项目，入口组件渲染一个时钟组件。
- 时钟组件在 `useEffect` 中通过 `setInterval` 每 1000ms 调用 `setTime(new Date())`，在 `useEffect` cleanup 中清除定时器。
- 格式化函数将 `Date` 的时、分、秒分别两位补零，拼接为 `HH:MM:SS`。
- 页面布局：全屏居中，大字号显示时间文本。

## 运行方式

- 开发：`npm run dev`（Vite 开发服务器）。
- 构建：`npm run build`（生产构建，输出至 `dist/`）。
- 声明的产物入口路径由实现阶段确定，本文档不虚构工作区路径。

## 架构边界

- 不涉及服务端、API、数据库、认证、后台任务或外部服务集成。
- 不涉及跨设备/跨用户数据同步。
- 所有逻辑在浏览器端完成，时间精度依赖客户端系统时钟。
