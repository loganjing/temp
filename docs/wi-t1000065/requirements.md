# KWMS 仓储费用管理模块（报价计费）需求

> 来源：用户提供的《KWMS仓储系统 报价计费模块需求说明书 V1.0》（`/Users/loganjing/work/codingtest/KWMS仓储系统.md`）。除单独标注「未规定」外，本文内容均为用户明确提出；本文档未引入推荐基线。

## 1. 目标与范围

统一管理货主仓储合作计费规则，系统依据合同配置自动定时核算仓储应收费用；支持人工修正费用、周期客户对账、财务结算开票、收款核销，实现仓储费用报价配置、自动计费、费用调整、对账、结算、开票核销全线上业务闭环，替代线下手工核算，保证计费标准统一、费用数据可追溯、对账结算流程标准化。

业务覆盖范围：仓租、装卸、操作、耗材、保险等全部仓储应收类费用；支持按库存数量、库位、体积、重量多维度计费，支持一口价、阶梯分段优惠、最低保底收费等商业计费模式。

## 2. 角色与权限

| 角色 | 可执行操作 | 明确禁止 |
| --- | --- | --- |
| 仓储运营人员 | 新增/编辑/续签合同报价、维护分段优惠、查询应收费用明细、发起费用调整单 | 对账审核、开票、核销 |
| 财务人员 | 费用重算、生成并审核应收对账单、结算单开票/核销、查看全量费用、导出财务报表 | 修改合同基础报价规则 |
| 系统管理员 | 维护基础档案（费用类型、货品类别）、配置角色数据权限、处理跨组织数据异常 | — |
| 客户经理（只读角色） | 查询所有单据 | 新增、编辑、审核、开票、重算 |

数据隔离规则：所有单据按组织机构隔离，用户仅能查看、操作所属组织下仓库、货主的数据，禁止跨组织查询/修改。

## 3. 核心业务旅程（端到端闭环）

合同报价配置 → 系统自动生成应收明细 → 人工费用调整 → 周期应收对账 → 应收结算单开票 → 收款核销。

1. 仓储运营创建仓储合同报价单（CCHT），配置费用明细行与分段优惠，审核生效后系统按账期自动计费。
2. 系统定时任务按结算账期生成应收费用明细；免租期内、效期外、未生效或已终止合同不产生费用。
3. 发现计费误差时：财务执行费用重算；或仓储运营发起应收费用调整单（YSTZ）修正误差、补录临时费用，审核生效后同步更新明细金额。
4. 财务按组织、仓库、结算方、业务周期生成应收对账单（YSDZ）并审核；审核通过后明细锁定为已对账，并自动生成应收结算单（YSJS）。
5. 财务在结算单上开票，累计开票金额不超过结算总金额。
6. 财务录入收款核销，累计核销金额不超过开票总金额，业务闭环完成。

## 4. 菜单与单据

该计费报价模块为单独一级菜单模块：在现有 KWMS 仓储云应用下的「仓储平台」模块中新增一级菜单「仓储费用管理」，其余单据菜单均放入该菜单下。

| 单据名称 | 编码前缀 | 核心用途 |
| --- | --- | --- |
| 仓储合同报价单 | CCHT | 维护货主计费单价、计费模式、免租期、分段优惠规则 |
| 应收费用明细 | 无独立编码（关联合同 + 业务周期） | 系统定时自动生成每日/月度计费明细 |
| 应收费用调整单 | YSTZ | 人工修正自动计费误差、新增临时增值费用 |
| 应收对账单 | YSDZ | 按周期汇总费用，用于与客户对账确认 |
| 应收结算单 | YSJS | 对账审核后自动生成，提供开票、收款核销功能 |

## 5. 单据功能需求

### 5.1 仓储合同报价单（CCHT）

**单据编码规则**：自动生成，格式 `CCHT-YYYYMMDD-00001`（YYYYMMDD = 制单日期，末尾 5 位为当日自增流水号），页面只读不可编辑。

**头部基础字段**：

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 合同编号 | 是 | 下拉选择，关联外部仓储合作合同，支持多报价单绑定同一合同 |
| 组织机构 | 是 | 下拉选择，过滤当前用户所属组织，数据隔离 |
| 仓库名称 | 是 | 下拉选择，仅展示所选组织下有效仓库，一单仅绑定单个仓库 |
| 货主类型 | 是 | 下拉选择：业务组织/客户，控制货主下拉数据源 |
| 货主 | 是 | 下拉选择，根据组织、货主类型过滤，一单仅绑定单个货主 |
| 合同效期-开始时间 | 是 | 日期选择，计费生效起始日，免租期从该日期起算 |
| 合同效期-结束时间 | 是 | 日期选择，计费截止日，到期后系统停止自动计费；开始时间必须早于结束时间 |
| 免租期 | 是 | 下拉选择 0/7/15/30 天；免租期内系统不生成任何费用明细；免租期结束日不可晚于合同结束日 |
| 结算账期 | 是 | 按天：每日 0 点自动计算前一日费用；按月：每月 1 日 0 点自动计算上月全月费用 |
| 结算方式 | 是 | 月结/现付，默认月结，预留扩展能力 |
| 需要保险 | 是 | 是/否，用于联动保险费自动计费 |
| 单据状态 | 系统赋值 | 只读：暂存/已生效/已终止；新建默认暂存 |
| 备注 | 否 | 文本输入，记录合同特殊计费约定、补充说明 |

**费用明细行**（支持增行、删行；每条明细代表单一费用类型计费规则，多费用分开配置）：

| 字段 | 必填条件 | 编辑控制规则 |
| --- | --- | --- |
| 费用类型 | 全部场景必填 | 基础档案：仓储费、装卸费、操作费、耗材费、保险费等 |
| 计费模式 | 全部场景必填 | 下拉：普通/一口价/取大值 |
| 计费方式 | 计费模式=普通时必填 | 下拉：按总库存数/按总库位数/按总体积/按总重量；一口价、取大值置灰不可编辑 |
| 货品类别 | 非必填 | 不同货品单价不同则选择；不选代表全货品共用一套单价 |
| 单价（元） | 计费模式≠一口价必填 | 正数，保留 2 位小数；一口价模式置灰 |
| 最低收费（元） | 非必填 | 正数，保留 2 位小数；为空代表无保底收费 |
| 金额（元） | 计费模式=一口价可编辑 | 固定总价，其余模式只读置灰 |

计费方式定义：按总库存数取计算费用时当前总库存数量；按总库位数取计算费用时所占用库位数量；按总体积取当前库存每个商品的总体积；按总重量取当前库存每个商品的总毛重。

三种计费模式基础计算规则：
- 普通模式：原始费用 = 当期业务量 × 单价；最终费用 = Max(原始费用, 最低收费)，无最低收费则取原始费用。
- 一口价模式：直接取明细行「金额」，不受业务量、单价、最低收费影响。
- 取大值模式：分别计算体积计费金额、重量计费金额，取两者较大值为基础费用，再对比最低收费取最大值。

**分段优惠弹窗**：选中单条费用明细，点击【分段优惠】弹出配置弹窗，优惠规则仅对当前费用类型生效。优惠明细支持增行、删行，字段约束：

| 字段 | 必填 | 约束 |
| --- | --- | --- |
| 业务量下限 | 是 | 数值≥0，保留 2 位小数 |
| 业务量上限 | 是 | 数值必须大于业务量下限；所有区间不可重叠、无断层 |
| 优惠方式 | 是 | 下拉：按百分比/固定金额 |
| 优惠百分比 | 优惠方式=按百分比必填 | 数值 0~100，不可负数 |
| 固定金额（元） | 优惠方式=固定金额必填 | 数值≥0，保留 2 位小数 |

**单据状态操作约束**：
- 暂存：可新增、编辑、删除明细，配置分段优惠；不参与系统自动计费。
- 已生效：审核通过后切换状态，系统按账期自动计费；不可修改计费规则，如需变更需终止旧合同、新建续签报价单。
- 已终止：合同到期或手动终止；不再生成新费用明细，历史已生成明细数据永久保留。

**保存校验规则（前端 + 后端双重校验）**：
1. 合同开始日期 < 合同结束日期；
2. 免租期结束日期 ≤ 合同结束日期；
3. 同一组织、仓库、货主、合同效期内，不允许存在两条生效的同费用类型 + 同货品类别明细；
4. 分段优惠区间禁止交叉、断层；
5. 单价、最低收费、优惠金额禁止输入负数；
6. 一口价模式下单价输入框锁定置灰。

异常拦截：同一货主、仓库、周期存在多份生效合同时，保存时直接拦截报错，提示终止旧合同。

### 5.2 应收费用明细（系统自动生成）

**自动生成触发时机**：账期=按天：每日 00:00 定时任务执行，计算前一日库存费用；账期=按月：每月 1 日 00:00 定时任务执行，批量计算上月整月费用。

**生成过滤条件**（须同时满足）：合同报价单状态=已生效；记账日期超出合同免租期；记账日期在合同效期起止范围内；取当期实时库存数据（库存数量、占用库位、总体积、总毛重）。

**费用重算**：
- 使用场景：合同计费规则修改后，历史明细金额错误。
- 操作流程：勾选多条明细，点击【费用重算】。
- 强限制：单据状态=已对账的明细禁止重算。
- 重算逻辑：清空原有计算金额，重新匹配最新生效合同规则、分段优惠重新核算。

**核心字段**：记账日期、组织机构、仓库、货主、费用类型、计费模式、计费方式、业务量、原始计算金额、优惠后计费金额、最低收费、货品类别、关联合同单号、单据状态（暂存/已对账）。

### 5.3 应收费用调整单（YSTZ）

**业务用途**：修正系统自动计费误差、临时增值服务、客户费用减免；新增无合同匹配的临时仓储费用。

**单据编码规则**：`YSTZ-YYYYMMDD-00001`，系统自动生成，只读。

**核心字段**：

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 业务周期（开始/结束） | 是 | 选定周期后，【添加费用明细】仅加载周期内暂存应收明细 |
| 费用类型 | 是 | 通过添加明细带出的行，费用类型锁定不可修改；手动新增空白行可自由选择 |
| 业务量 | 否 | 带出原明细业务量，支持手动修改 |
| 调整前金额 | 系统带出 | 只读，展示原始计费金额 |
| 调整金额 | 是 | 仅支持输入正数；调减业务通过新增反向调整单实现 |
| 调整后金额 | 自动计算 | 调整前金额 ± 调整金额 |
| 调整原因 | 是 | 文本录入，记录调整依据（库存误差、临时服务费、客户减免等） |
| 单据状态 | 系统赋值 | 暂存/已生效；生效后同步更新应收费用明细计费金额 |

**操作逻辑**：选择业务周期 → 点击【添加费用明细】批量加载周期内未对账明细；支持手动新增空白行自定义新增临时费用；调整单审核生效后，同步更新对应应收费用明细金额，生成完整变更日志。

### 5.4 应收对账单（YSDZ）

**单据编码规则**：`YSDZ-YYYYMMDD-00001`，自动生成只读。

**生成与汇总逻辑**：按组织机构、仓库、结算方、业务周期汇总应收费用明细；仅加载单据状态=暂存的应收明细，已对账明细自动过滤不展示；单据审核通过后：①关联应收明细统一更新状态为【已对账】；②自动生成对应应收结算单。

**页面核心字段**：业务周期（必选）、结算方、总金额（自动汇总只读）、单据状态（暂存/审核通过）、备注；明细行字段：货品类别、记账日期、费用类型、计费模式、业务量、单价、最低收费、计算金额、最终计费金额。

**状态约束**：单据审核通过后，明细不可新增、删除、编辑。

### 5.5 应收结算单（YSJS）

**生成规则**：应收对账单审核通过后，系统自动创建一一绑定的应收结算单。

**单据编码**：`YSJS-YYYYMMDD-00001`，自动生成只读。

**头部金额字段**（全部只读，系统自动累加）：
- 对账总金额：同步对应对账单总金额。
- 结算总金额：默认等于对账总金额，支持少量抹零人工微调。
- 开票总金额：所有开票记录累加；约束开票总金额 ≤ 结算总金额。
- 核销总金额：所有收款核销记录累加；约束核销总金额 ≤ 开票总金额。

**开票功能**：点击【开票】弹窗录入开票人、发票号码、本次开票金额；提交后新增开票明细，开票总金额实时更新；拦截规则：累计开票金额超过结算总金额时弹窗禁止提交。

**核销功能**：前置条件为存在有效开票记录才可核销；弹窗录入本次核销金额，提交后核销总金额累加；拦截规则：累计核销金额不可大于累计开票金额；业务含义为核销代表已收到客户对应款项。

**标签页**：费用明细（展示对账原始计费明细）；开票明细（记录开票日期、发票号码、开票金额）。

**状态**：暂存（可开票/核销），无终态，永久留存开票、核销记录。

## 6. 后台定时任务

- 按天计费定时任务：执行时间每日 00:00；筛选前一日库存数据，匹配生效合同生成应收明细；跳过免租期、过期合同；异常日志记录失败单据。
- 按月计费定时任务：执行时间每月 1 日 00:00；汇总上月全月库存，批量生成月度应收明细。
- 合同过期检测任务：每日凌晨执行，自动将到期合同报价单标记为「已终止」，停止后续计费。

## 7. 统一计费与优惠计算逻辑

完整计费计算公式：
1. 根据计费模式计算基础金额；
2. 判断当期业务量匹配的分段优惠区间：
   - 百分比优惠：优惠后金额 = 基础金额 × (1 - 优惠百分比 / 100)；
   - 固定金额优惠：优惠后金额 = 基础金额 - 固定优惠金额（结果小于 0 则置 0）；
3. 优惠后金额与最低收费对比，取最大值作为最终计费金额。

## 8. 全单据状态流转规则

- 仓储合同报价单：暂存 → 审核 → 已生效 → 到期/手动终止 → 已终止。
- 应收费用明细：暂存 → 对账审核 → 已对账（锁定不可重算）。
- 应收费用调整单：暂存 → 审核 → 已生效（同步更新明细金额）。
- 应收对账单：暂存 → 审核通过（自动生成结算单，明细锁定）。
- 应收结算单：暂存（可开票/核销），无终态，永久留存开票、核销记录。

## 9. 数据日志与追溯规范

- 所有单据操作日志：记录操作人、操作时间、操作类型（新增/编辑/审核/重算/开票/核销）。
- 费用重算、费用调整变更日志：记录调整前后金额、调整原因。
- 合同报价修改日志：记录修改前后单价、优惠区间、计费规则。
- 报表导出：支持按货主、仓库、业务周期导出计费、对账、结算 Excel 报表。

## 10. 异常场景处理方案

1. 定时任务执行时库存数据缺失：记录异常日志，推送消息提醒仓储运营人工触发重算。
2. 同一货主、仓库、周期存在多份生效合同：保存时直接拦截报错，提示终止旧合同。
3. 优惠后金额为负数：系统自动修正为 0。
4. 添加对账明细时包含已对账数据：系统自动过滤，不展示。
5. 开票金额超结算总额、核销金额超开票总额：前端弹窗拦截，禁止提交。
6. 分段优惠区间重叠：保存合同时报错，提示重新调整业务量区间。

## 11. 非功能性需求

- 性能：月度批量计费任务支持 10 万条库存数据，5 分钟内完成计算。
- 兼容性：PC 端浏览器适配，Excel 导出支持万行明细无卡顿。
- 数据安全：跨组织数据隔离，财务金额字段仅财务角色可见。
- 扩展性：费用类型、计费方式、优惠方式通过后台基础档案维护，无需修改代码。
- 交互提示：所有必填项、数值超限、区间冲突给出清晰中文提示。

## 12. 未规定事项

以下缺口影响核心验收或下游必须决策，保持未规定，不做推断：

1. 按月账期的业务量取值口径：按月任务「汇总上月全月库存，批量生成月度应收明细」，但按总体积/总重量/总库位等计费方式在月度口径下取月末库存快照还是月内汇总值未明确，直接影响计费金额与人工演算一致性（AC-02、AC-03）。
2. 金额舍入规则：单价、最低收费、固定优惠金额保留 2 位小数已明确，但原始计算金额、优惠后计费金额、最终计费金额的小数位保留与舍入方式未明确，影响计算一致性验收（AC-02、AC-03）。
3. 报价单与费用调整单的审核角色：仓储运营可发起调整单、财务可审核对账单已明确，但报价单（暂存→已生效）与调整单（暂存→已生效）的审核操作由哪个角色执行未明确，影响权限验收（AC-11）。
4. 仓储运营查询应收明细时金额字段可见性：数据安全要求「财务金额字段仅财务角色可见」，与仓储运营「查询应收费用明细」存在解释空间（运营查询时是否可见金额字段）未明确，影响数据隔离与权限验收口径（AC-10、AC-11）。

## 13. 验收场景

### AC-01：合同报价单可创建、通过双重校验并审核生效
- 验收条件：新建仓储合同报价单，填写头部字段与费用明细行，前后端双重校验通过后保存成功；审核后单据由暂存变为已生效并参与自动计费。
- 入口类型：用户界面
- 验证动作：
  1. 新建报价单，必填字段留空尝试保存；
  2. 补全字段后设置合同开始日期晚于结束日期尝试保存；
  3. 修正日期后，在同一组织、仓库、货主、效期内配置第二条同费用类型+同货品类别的生效明细尝试保存；
  4. 修正后保存成功，核对单据编号格式 `CCHT-YYYYMMDD-00001` 及只读性，检查一口价明细行的单价字段置灰；
  5. 执行审核。
- 预期结果：步骤 1-3 分别因必填缺失、日期先后错误、明细重复被中文提示拦截；步骤 4 保存成功，单据编号自动生成且只读不可编辑，一口价模式单价输入框锁定置灰；步骤 5 审核通过后单据状态变为「已生效」。
- 证据类型：interaction, runtime-render, error-feedback

### AC-02：三种计费模式计算结果与人工演算一致
- 验收条件：已生效合同分别按普通、一口价、取大值三种模式计费，生成的应收明细金额与人工演算完全一致。
- 入口类型：后台任务
- 验证动作：准备一份已生效合同（结算账期与测试任务对齐），费用明细行分别配置：普通模式（按总库存数，含最低收费）、一口价模式、取大值模式（含最低收费）；触发对应账期定时任务后在应收费用明细页面查看各明细行的原始计算金额与优惠后计费金额。
- 预期结果：普通模式原始费用=当期业务量×单价，最终费用=Max(原始费用, 最低收费)，无最低收费时取原始费用；一口价模式金额直接取明细行「金额」，不受业务量、单价、最低收费影响；取大值模式分别计算体积计费金额与重量计费金额，取较大者为基础费用后再与最低收费取最大值。
- 证据类型：runtime-render, other
- 共享流程组：自动计费

### AC-03：分段优惠计算正确且优惠后金额非负
- 验收条件：配置分段优惠的合同在计费时按当期业务量匹配唯一优惠区间并正确应用；固定金额优惠导致负数时自动修正为 0。
- 入口类型：后台任务
- 验证动作：在合同费用明细上配置不重叠、无断层的分段优惠区间（按百分比与固定金额各一段），触发定时计费后查看明细优惠后计费金额；另构造固定优惠金额大于基础金额的场景观察结果。
- 预期结果：百分比优惠的优惠后金额=基础金额×(1-优惠百分比/100)；固定金额优惠的优惠后金额=基础金额-固定优惠金额，结果小于 0 时置 0；优惠后金额再与最低收费取最大值作为最终计费金额；业务量落入区间时仅命中一条优惠规则。
- 证据类型：runtime-render, other
- 共享流程组：自动计费

### AC-04：定时计费任务按时执行并完成免租期与效期过滤
- 验收条件：按天/按月账期在约定时点自动生成应收明细；免租期内、效期外、未生效或已终止的合同不产生任何明细；到期合同被自动标记终止。
- 入口类型：后台任务
- 验证动作：准备多份合同：①已生效且当前处于免租期内；②已生效且超出免租期；③结束日期早于计算日（已过期）；④暂存状态；⑤已生效且到期日到期。分别验证按天任务（每日 00:00 计算前一日费用）与按月任务（每月 1 日 00:00 计算上月费用）执行后的明细生成结果与合同状态。
- 预期结果：仅合同②生成应收明细；合同①免租期内无任何费用产出；合同③、⑤不再生成新费用明细，且到期合同被合同过期检测任务标记为「已终止」；合同④暂存状态不参与自动计费；任务执行失败的库存缺失单据记录异常日志。
- 证据类型：runtime-render, other
- 共享流程组：自动计费

### AC-05：费用重算仅对未对账明细生效
- 验收条件：勾选未对账明细执行费用重算，清空原金额并按最新生效合同规则与分段优惠重新核算；已对账明细禁止重算。
- 入口类型：用户界面
- 验证动作：
  1. 终止旧合同并新建续签报价单调整规则后，勾选历史未对账明细点击【费用重算】；
  2. 勾选单据状态为已对账的明细尝试点击【费用重算】。
- 预期结果：步骤 1 原计算金额被清空并按最新生效规则与优惠重新核算，重算变更日志记录调整前后金额与原因；步骤 2 已对账明细被拦截禁止重算并给出提示。
- 证据类型：interaction, error-feedback, runtime-render

### AC-06：费用调整单审核生效后同步更新应收明细金额
- 验收条件：调整单按业务周期加载暂存明细或手动新增空白行，录入正数调整金额与调整原因，审核生效后对应应收费用明细计费金额同步更新。
- 入口类型：用户界面
- 验证动作：新建调整单，选择业务周期后点击【添加费用明细】；尝试在调整金额输入负数；改为正数并填写调整原因后保存并审核；再手动新增空白行录入无合同匹配的临时费用。
- 预期结果：仅加载周期内未对账（暂存）明细，带出行的费用类型锁定不可修改；负数调整金额被拦截（调减须新增反向调整单）；审核生效后调整后金额=调整前金额±调整金额同步写回对应应收明细，并生成含调整前后金额与调整原因的完整变更日志；手动空白行可自由选择费用类型作为临时费用。
- 证据类型：interaction, error-feedback, runtime-render

### AC-07：对账单汇总正确、审核锁定明细并自动生成结算单
- 验收条件：对账单按组织、仓库、结算方、业务周期汇总暂存应收明细，总金额自动汇总只读；审核通过后明细锁定不可增删改、关联明细更新为已对账，并自动创建一一绑定的应收结算单。
- 入口类型：用户界面
- 验证动作：生成对账单时确认已对账明细被自动过滤不展示；核对总金额与明细最终计费金额汇总一致；审核通过后尝试新增、删除、编辑明细行；打开自动生成的结算单核对对账总金额。
- 预期结果：已对账数据不出现在对账单明细中；总金额自动汇总且只读；审核通过后明细不可新增、删除、编辑，关联应收明细状态更新为「已对账」；结算单自动生成且与对账单一一绑定，对账总金额与对账单总金额完全一致（金额数据完全联动）。
- 证据类型：interaction, runtime-render

### AC-08：开票累计金额受结算总金额控制
- 验收条件：结算单开票为弹窗录入开票人、发票号码、本次开票金额；累计开票金额不超过结算总金额，超额时弹窗拦截禁止提交；开票总金额实时累加。
- 入口类型：用户界面
- 验证动作：在结算单点击【开票】录入信息提交，重复开票至累计金额等于结算总金额；随后再次尝试提交使累计金额超过结算总金额；核对开票明细标签页与头部开票总金额。
- 预期结果：正常开票提交成功，开票明细新增记录（开票日期、发票号码、开票金额），头部开票总金额实时累加更新；超额提交被弹窗拦截禁止提交。
- 证据类型：interaction, error-feedback, runtime-render
- 共享流程组：结算开票核销

### AC-09：核销受开票前置条件与开票总额控制
- 验收条件：存在有效开票记录才可核销；累计核销金额不超过开票总金额；核销代表已收到客户对应款项。
- 入口类型：用户界面
- 验证动作：对无任何开票记录的结算单尝试核销；完成开票后录入本次核销金额提交；累计核销至等于开票总金额后再次尝试超额核销。
- 预期结果：无有效开票记录时核销被拦截；正常核销提交后核销总金额累加；累计核销金额超过累计开票金额时弹窗拦截禁止提交。
- 证据类型：interaction, error-feedback, runtime-render
- 共享流程组：结算开票核销

### AC-10：单据按组织机构隔离
- 验收条件：所有单据按组织机构隔离，用户仅能查看、操作所属组织下仓库、货主的数据，禁止跨组织查询/修改。
- 入口类型：用户界面
- 验证动作：使用组织 A 账号创建合同报价单、费用明细、对账单、结算单；切换为组织 B 账号查询各类单据列表，并尝试通过单据编码访问组织 A 的单据详情。
- 预期结果：组织 B 用户在列表与详情中均无法查看或修改组织 A 的单据数据；组织机构的下拉数据源仅过滤出当前用户所属组织。
- 证据类型：authorization, error-feedback

### AC-11：四类角色权限边界生效
- 验收条件：仓储运营、财务、系统管理员、客户经理（只读）按角色定义行使权限，越权操作被拒绝。
- 入口类型：用户界面
- 验证动作：分别以四类角色登录，执行职责内与职责外操作：仓储运营尝试对账审核、开票、核销；财务尝试修改合同基础报价规则；客户经理尝试新增/编辑/审核单据；系统管理员维护费用类型与货品类别基础档案并配置角色数据权限。
- 预期结果：仓储运营可新增/编辑/续签报价、维护分段优惠、查询应收明细、发起调整单，对账审核、开票、核销被拒绝；财务可执行费用重算、生成并审核对账单、开票/核销、查看全量费用、导出报表，修改合同报价规则被拒绝；系统管理员可维护基础档案与角色数据权限；客户经理仅可查询所有单据，全部写操作被拒绝。
- 证据类型：authorization, error-feedback

### AC-12：操作日志完整可追溯且报表支持 Excel 导出
- 验收条件：所有单据操作记录操作人、操作时间、操作类型；重算与调整记录调整前后金额与原因；合同修改记录前后单价、优惠区间、计费规则；支持按货主、仓库、业务周期导出计费、对账、结算 Excel 报表。
- 入口类型：用户界面
- 验证动作：完成一轮包含新增报价、调整、重算、对账审核、开票、核销的操作后查询各类日志；分别按货主、仓库、业务周期导出计费、对账、结算报表并打开核对。
- 预期结果：日志条目完整可查询追溯，字段（操作人、时间、类型）齐全，变更类日志含前后金额与原因，合同修改日志含前后单价、优惠区间、计费规则；导出的 Excel 内容与系统单据数据一致，万行明细导出无卡顿。
- 证据类型：runtime-render, other

### AC-13：月度批量计费性能达标
- 验收条件：月度批量计费任务在 10 万条库存数据规模下 5 分钟内完成计算。
- 入口类型：后台任务
- 验证动作：构造 10 万条库存数据及对应已生效合同，执行按月计费任务并记录任务执行耗时与生成明细数量。
- 预期结果：任务在 5 分钟内完成计算，生成的月度应收明细数据完整无缺失。
- 证据类型：other
