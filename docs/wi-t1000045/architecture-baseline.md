# k08-clock 架构基线

> 批准需求基线：`docs/wi-t1000045/requirements.md`（sha256: 1ec2bd1ec21c2391b4610b411301c79e7ce2a1bab25f68c3edb36fba95040a9e）

## 应用类型

simple-frontend（精简前端路线）。应用为纯浏览器端实时时钟页面，无服务端、无数据库、无认证、无外部集成。

## 页面与交互范围

- 单页面 SPA，页面中心区域以 `HH:MM:SS`（24 小时制）格式实时显示当前时分秒。
- 页面加载后立即显示当前时间，之后每秒自动更新一次，无需用户操作或手动刷新。
- 无用户交互控件、无路由跳转、无表单、无数据持久化需求。

## 浏览器状态与数据归属

- 时间数据来源：浏览器 `Date` 对象，取用户本地系统时间。
- 数据归属：只读运行时数据，不写入 `localStorage` 或任何持久化存储。时间在每次渲染时从 `new Date()` 获取，无跨页面、跨设备或跨用户共享。
- 无服务端权威数据边界。

## 实现入口与运行方式

- 技术栈：React + Vite + TypeScript SPA。
- 应用入口：`index.html` → `src/main.tsx` 渲染根组件 `App`，`App` 内包含时钟组件。
- 时钟更新机制：组件挂载时通过 `setInterval(callback, 1000)` 每秒触发状态更新，回调中调用 `new Date()` 获取最新时间并更新 React state，驱动 DOM 重渲染。组件卸载时 `clearInterval` 清除定时器。
- 时间格式化：使用 `String.padStart(2, '0')` 将时、分、秒补零至两位，拼接为 `HH:MM:SS`。
- 开发运行：`npm run dev` 启动 Vite 开发服务器。
- 构建产物：`npm run build` 输出静态资源，可部署至任意静态文件服务器。

## UI 组件体系与视觉方向

- 该应用为单一信息展示页面，非管理工作台，不适用 Ant Design 默认方案。
- 采用最小化自定义 CSS 方案：深色背景、居中大字号等宽字体显示时间，确保可读性。
- 不引入额外 UI 组件库，保持产物轻量。

## 验收验证方式

- AC-01 涉及定时自动更新，验证方式：
  - 打开页面后直接观察时间显示，确认格式为 `HH:MM:SS`。
  - 等待数秒，确认显示数值每秒变化且与本地系统时间一致。
  - 该 AC 的核心行为（每秒更新、格式正确）可由确定状态直接验证：页面渲染后 `setInterval` 以 1000ms 间隔触发，时间值来自 `new Date()`，格式化逻辑为纯函数，无随机性或外部异步依赖。
  - 无需预置状态或手动触发事件；刷新页面即可恢复初始态。

## 边界约束

- 不生成 `technical-contract.md`、`workspace-bootstrap.json` 或 ADR。
- 产品语义以批准需求基线为准，设计仅提供技术承载方式。
