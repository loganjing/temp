# k08-clock 需求

## 目标

提供一个页面，实时显示当前的时、分、秒。

## 核心行为

- 页面加载后立即显示当前时间，格式为 `HH:MM:SS`（24 小时制）。
- 时间显示每秒自动更新，无需用户手动刷新。
- 时分秒取自用户本地系统时间。

## 验收场景

### AC-01：页面实时显示当前时分秒

- 验收条件：页面加载后显示当前时间，且每秒自动更新。
- 入口类型：用户界面
- 验证动作：打开页面，观察时间显示。
- 预期结果：页面显示格式为 `HH:MM:SS` 的当前时分秒，且数值随时间推移每秒自动变化，与用户本地系统时间一致。
- 证据类型：runtime-render
