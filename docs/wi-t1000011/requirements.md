# 需求文档：实时时钟页面

## 目标

做一个页面，实时显示当前的时、分、秒。

## 核心行为与规则

- 页面展示当前时间，格式为时:分:秒（HH:MM:SS）。
- 时间随系统时钟实时更新，每秒刷新一次（用户明确提出"实时"；刷新间隔为推荐基线，因最小显示粒度为秒，1 秒间隔是覆盖该目标的最小保守默认值，可调整）。
- 页面打开后即开始显示当前时间，无需用户手动触发。
- 页面关闭或不可见时停止更新，重新可见时恢复当前时间显示。

## 验收场景

### AC-01：页面打开后实时显示当前时分秒

- 验收条件：页面展示当前时间的时、分、秒，且随时间推移自动更新。
- 入口类型：用户界面
- 验证动作：打开页面，观察时间显示。
- 预期结果：页面显示格式为 HH:MM:SS 的当前时间；间隔不超过 1 秒后，显示的时间值发生变化并仍与当前系统时间一致。
- 证据类型：runtime-render
