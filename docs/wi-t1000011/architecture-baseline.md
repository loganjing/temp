# 架构基线：实时时钟页面

> 需求基线：`docs/wi-t1000011/requirements.md`（SHA-256: `02abddd0dc25a99a88e1df039245699aad94bb9b4d30dddb95e2e66306c7ce11`）

## 路线

`simple-frontend`（compact）。应用不涉及服务端权威数据、数据库、认证、后台任务或外部集成，时间数据完全来自浏览器本地时钟。

## 页面与交互范围

- 单页面 SPA，打开后立即在页面中央显示当前时间，格式为 `HH:MM:SS`。
- 使用 `setInterval` 以 1000ms 间隔定时刷新显示值，满足"实时"且刷新间隔不超过 1 秒的需求。
- 页面加载后自动启动时钟，无需用户手动触发。
- 利用 Page Visibility API（`visibilitychange` 事件）在页面不可见时暂停定时器，重新可见时恢复刷新并立即同步到当前时间。

## 浏览器状态与数据归属

- 时间数据来源：浏览器运行时的 `new Date()`，不涉及持久化存储。
- 无需 `localStorage` 或其他客户端存储——页面仅展示实时时钟，关闭后无状态需要保留。
- 数据仅在当前浏览器标签页/窗口生命周期内有效，不跨浏览器、跨设备或跨用户共享。

## 实现入口与运行方式

- 技术栈：React + Vite SPA（新应用）。
- 实现入口：应用根组件渲染一个时钟组件，组件内部管理定时器与可见性切换逻辑。
- 运行方式：Vite 开发服务器，`npm run dev` 启动本地开发预览。

## 技术边界

- 不引入服务端、API、数据库、认证、后台任务或第三方集成。
- 不引入数据持久化或同步层。
- 组件卸载时清理定时器，避免内存泄漏。
