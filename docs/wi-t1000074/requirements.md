# 工单系统需求文档

> Work Item: wi-t1000074 | Code: T1000074 | 项目: JLGSpace-88

## 1. 目标与范围

构建一个面向多公司的工单管理系统，覆盖工单从创建、分配、处理到完成/取消的完整生命周期，支持工单分配与转派协作、SLA 优先级管理、用户满意度评价、统计分析仪表盘和工单工作台。

工单数据按公司隔离，不同公司的工单互不可见。

**用户明确提出的功能模块：**
- 工单管理（字段、多轮回复、公司隔离、SLA 优先级、生命周期）
- 工单分配（业务组、按分类自动分配）
- 工单协作（转派）
- 工单处理（提交人信息查看、处理记录、邮件通知）
- 用户评价（满意度评价）
- 统计分析（分布统计、运营仪表盘）
- 工单工作台（待处理列表、筛选搜索排序）
- 操作日志

## 2. 角色与权限边界

以下角色由用户需求隐含定义，非额外推断：

| 角色 | 说明 | 来源 |
|------|------|------|
| 提交人 | 创建工单、回复工单、接收完成通知、进行满意度评价的用户 | 用户明确提出"提交人信息"、"用户评价" |
| 处理人 | 业务组成员，接收分配/转派的工单并进行处理、回复 | 用户明确提出"处理人"、"业务组成员" |
| 管理员 | 为公司配置业务组及成员、配置分类自动分配规则 | 用户明确提出"允许给某个公司增加多个业务组"、"按照分类自动分配" |

**数据隔离规则（用户明确提出）：** 工单按公司隔离，用户只能访问本公司的工单及相关数据。

## 3. 工单生命周期

用户明确提出的状态：创建、待分配、待处理、完成、取消。

```
创建 → 待分配 → 待处理 → 完成
                ↗          ↘
  待分配/待处理 ────────→ 取消
```

| 状态 | 含义 | 触发条件 |
|------|------|----------|
| 创建 | 工单刚被提交 | 提交人填写工单信息并提交 |
| 待分配 | 工单已创建，等待分配到业务组或处理人 | 工单提交后进入此状态 |
| 待处理 | 工单已分配到业务组/处理人，等待处理 | 手动分配或按分类自动分配后进入此状态 |
| 完成 | 工单已处理完毕 | 处理人标记完成后进入此状态，触发邮件通知 |
| 取消 | 工单被取消 | 待分配或待处理状态下可取消 |

**SLA 优先级（用户明确提出）：** 支持 P0、P1、P2、P3、P4 五个优先级。

**问题分类（用户明确提出）：** 工单支持按问题类型进行分类，分类用于工单管理和自动分配规则。

## 4. 功能模块需求

### 4.1 工单管理

**工单字段（用户明确提出）：**
- 工单 ID：唯一标识
- 主题
- 描述
- 分类（问题分类）
- SLA 优先级（P0-P4）
- 提交人信息（含姓名、邮箱、公司、部门）
- 创建时间
- 当前状态

**多轮回复（用户明确提出）：**
- 工单支持多轮回复，每条回复记录回复人和回复时间。
- 回复内容在工单详情中按时间排列展示。

**公司隔离（用户明确提出）：**
- 工单归属于提交人所在公司。
- 用户只能查看和操作本公司的工单。

### 4.2 工单分配

**业务组管理（用户明确提出）：**
- 允许给某个公司增加多个业务组。
- 每个业务组可以设置成员。

**按分类自动分配（用户明确提出）：**
- 允许为某个公司配置"分类 → 业务组"的自动分配规则。
- 工单创建后，若该公司已配置匹配的分类规则，则自动分配到对应业务组，工单状态从"待分配"流转为"待处理"。

### 4.3 工单协作

**转派（用户明确提出）：**
- 支持工单转派操作，可将工单转派给其他处理人或业务组。
- 转派操作需记录转派人、转派目标和转派时间。

### 4.4 工单处理

**提交人信息查看（用户明确提出）：**
- 处理工单时可查看提交人的完整信息，包括：姓名、公司、部门、历史工单列表。

**处理记录（用户明确提出）：**
- 工单处理完成后，记录处理人和处理时间。

**邮件通知（用户明确提出）：**
- 工单状态变为"完成"时，向提交人邮箱发送完成通知邮件。

### 4.5 用户评价

**满意度评价（用户明确提出）：**
- 工单完成后，提交人可对工单处理结果进行满意度评价。
- 评价与已完成工单关联。

> 评价的具体评分形式（如星级、分数）用户未规定，保持未规定，不指定具体分制。

### 4.6 统计分析

**工单分布统计（用户明确提出）：**
- 支持按公司维度统计工单分布。
- 支持按部门维度统计工单分布。

**运营仪表盘（用户明确提出）：**
- 查看工单量。
- 查看平均响应时间。
- 查看满意度。
- 查看热点问题。

### 4.7 工单工作台

**待处理工单列表（用户明确提出）：**
- 查看待处理工单列表。
- 支持筛选（含按公司维度筛选）。
- 支持搜索。
- 支持排序。

### 4.8 操作日志

**日志记录（用户明确提出）：**
- 记录工单相关操作日志，包括但不限于：创建、分配、转派、处理、完成、取消等操作。
- 日志记录操作人、操作类型和操作时间。

## 5. 验收场景

### AC-01：提交人可创建工单并管理核心字段，工单按公司隔离且遵循生命周期

- 验收条件：提交人创建工单后，工单包含完整字段（ID、主题、描述、分类、SLA 优先级、提交人信息含邮箱、创建时间），状态为"待分配"；不同公司的用户无法看到对方公司的工单；工单状态可在生命周期各状态间正确流转（待分配→待处理→完成，以及取消）。
- 入口类型：用户界面
- 验证动作：提交人在工单创建入口填写主题、描述、分类、SLA 优先级后提交工单；用另一公司账号尝试查看该工单。
- 预期结果：工单创建成功并包含所有必填字段，初始状态为"待分配"；另一公司账号无法查看到该工单。
- 证据类型：runtime-render, interaction, session-persistence, authorization

### AC-02：工单支持多轮回复，每条回复记录回复人和回复时间

- 验收条件：工单详情中可添加回复，回复按时间排列展示，每条回复显示回复人和回复时间。
- 入口类型：用户界面
- 验证动作：在已创建工单的详情中连续添加多条回复。
- 预期结果：所有回复按时间排列展示，每条回复显示回复人信息和回复时间。
- 证据类型：runtime-render, interaction

### AC-03：管理员可为公司配置业务组与成员，工单按分类自动分配到业务组

- 验收条件：管理员可为公司创建多个业务组并设置成员；配置"分类→业务组"自动分配规则后，新建工单的分类匹配规则时，工单自动分配到对应业务组，状态流转为"待处理"。
- 入口类型：用户界面
- 验证动作：管理员创建业务组并添加成员，配置某分类的自动分配规则；提交人创建该分类的工单。
- 预期结果：业务组和成员创建成功；新工单自动分配到对应业务组，状态变为"待处理"。
- 证据类型：runtime-render, interaction, session-persistence

### AC-04：处理人可转派工单给其他处理人或业务组

- 验收条件：待处理状态的工单可被转派，转派后工单归属更新，转派操作记录转派人、转派目标和转派时间。
- 入口类型：用户界面
- 验证动作：处理人在待处理工单上执行转派操作，选择目标处理人或业务组。
- 预期结果：工单转派成功，工单归属更新为目标处理人或业务组；转派记录可查。
- 证据类型：runtime-render, interaction, session-persistence

### AC-05：处理人完成工单后记录处理信息并触发邮件通知

- 验收条件：处理人将工单标记为完成后，记录处理人和处理时间，工单状态变为"完成"，提交人邮箱收到完成通知邮件。
- 入口类型：用户界面
- 验证动作：处理人在待处理工单上执行完成操作。
- 预期结果：工单状态变为"完成"，处理人和处理时间被记录，提交人邮箱收到通知邮件。
- 证据类型：runtime-render, interaction, session-persistence

### AC-06：处理工单时可查看提交人完整信息含历史工单

- 验收条件：处理工单时可查看提交人完整信息，包括姓名、公司、部门和历史工单列表。
- 入口类型：用户界面
- 验证动作：处理人打开待处理工单详情，查看提交人信息区域。
- 预期结果：显示提交人姓名、公司、部门信息，以及该提交人的历史工单列表。
- 证据类型：runtime-render

### AC-07：工单完成后提交人可进行满意度评价

- 验收条件：工单完成后，提交人可对工单进行满意度评价，评价与已完成工单关联。
- 入口类型：用户界面
- 验证动作：提交人在已完成的工单上执行满意度评价操作。
- 预期结果：评价提交成功，评价结果与该工单关联并可查看。
- 证据类型：runtime-render, interaction, session-persistence

### AC-08：统计分析支持按公司/部门维度统计工单分布，仪表盘展示运营指标

- 验收条件：可按公司维度和部门维度统计工单分布；仪表盘展示工单量、平均响应时间、满意度和热点问题等运营指标。
- 入口类型：用户界面
- 验证动作：进入统计分析/仪表盘页面，切换公司维度和部门维度查看工单分布。
- 预期结果：工单分布按所选维度正确展示；仪表盘展示工单量、平均响应时间、满意度和热点问题指标。
- 证据类型：runtime-render

### AC-09：工单工作台展示待处理工单列表，支持筛选、搜索和排序

- 验收条件：工单工作台展示待处理工单列表，支持按公司维度筛选、关键词搜索和字段排序。
- 入口类型：用户界面
- 验证动作：进入工单工作台，使用公司筛选、关键词搜索和排序功能。
- 预期结果：列表按筛选、搜索和排序条件正确展示待处理工单。
- 证据类型：runtime-render, interaction

### AC-10：工单相关操作记录日志，包含操作人、操作类型和操作时间

- 验收条件：工单的创建、分配、转派、处理、完成、取消等操作均记录日志，日志包含操作人、操作类型和操作时间。
- 入口类型：用户界面
- 验证动作：执行工单创建、分配、转派、完成、取消等操作后，查看工单操作日志。
- 预期结果：每个操作均有对应日志记录，包含操作人、操作类型和操作时间。
- 证据类型：runtime-render, session-persistence
