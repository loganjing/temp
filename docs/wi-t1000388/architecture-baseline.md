# 190-clock 架构基线

> 需求基线：`docs/wi-t1000388/requirements.md`（sha256: 698d6c731d5a54656798882d04294e5f4c74bc6834ce01889b3d1d5ab3ca98ea）
> 路线：simple-frontend（compact）

## 页面与交互范围

单页面应用，唯一视图为一面实时时钟：

- 页面打开后立即显示当前系统时间的时、分、秒，格式 `HH:MM:SS`（两位补零）。
- 时间每秒自动更新，用户无需手动刷新。
- 无导航、无路由、无用户输入、无表单交互。

## 浏览器状态与数据归属

本应用不产生需要持久化的业务数据。时钟显示的时间来源于浏览器运行时的 `Date` 对象（读取用户系统本地时间），每秒重新读取并渲染，不写入 `localStorage` 或任何存储。

- 时间数据仅在当前页面会话中存在，属于瞬时渲染状态，刷新或重开后重新从系统时间读取。
- 不涉及跨浏览器、跨设备或跨用户的数据共享。

## 实现入口与运行方式

- 技术栈：React + Vite SPA（新建应用）。
- 组件结构：单一根组件 `Clock`，内部使用 `setInterval`（1000ms）定时调用 `setState` 更新时间字符串。
- 渲染：将 `Date` 对象格式化为 `HH:MM:SS` 字符串后直接渲染到 DOM。
- 运行方式：`npm run dev` 启动 Vite 开发服务器，浏览器访问开发服务器地址即可查看页面。

## 验证说明（AC-01）

AC-01 涉及定时自动推进（每秒更新），验证方式如下：

- **确定状态验证**：页面初始渲染时，显示的时间字符串应与打开瞬间的系统时间一致（允许 ±1 秒误差）。
- **定时推进验证**：在页面停留 ≥3 秒，观察秒位每秒递增；当秒位从 59 跨至 00 时，观察分位递增；当分位从 59 跨至 00 时，观察时位递增。
- **恢复初态**：刷新页面即可重置为当前系统时间，无需额外清理。
