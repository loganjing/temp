# 架构基线：k13-clock

> 批准需求基线：`docs/wi-t1000054/requirements.md`（sha256: 33f5c138565e68d5d62038c391f16d96a73b10f77ac0dc0fe8125386cf4de2df）
> 分类路线：simple-frontend / compact

## 页面与交互范围

单一实时时钟页面：打开后居中显示当前时分秒，格式 `HH:MM:SS`，随系统时钟每秒自动更新，用户无需手动刷新。无导航、无表单、无数据录入、无多页面跳转。

## 技术承载

- 应用形态：React + Vite 静态 SPA，单主组件承载时钟显示。
- 时间源：浏览器 `Date` API（客户端系统时钟），无服务端时间接口。
- 更新机制：组件挂载后通过 `setInterval` 以 1000ms 周期读取系统时间并更新 React 状态；卸载时清除定时器。
- 显示格式：两位补零的 `时:分:秒`，例如 `09:05:03`。
- 数据归属：无持久化需求。时间始终取自系统时钟的当前值，不写入 `localStorage` 或任何存储；刷新或重开页面后从当前系统时间重新开始显示。

## UI 选型

本页面为单一展示型组件，非管理工作台，不引入 Ant Design。采用 React + 自定义 CSS：居中大字号数字、中性背景，保持视觉简洁。不使用 emoji 或 Unicode 图标作为界面元素。

## 实现入口与运行方式

- SPA 入口：Vite 标准 React 入口，主时钟组件渲染于应用根视图。
- 开发运行：`npm run dev`，由 Vite 开发服务器提供本地预览地址。
- 构建产物：`npm run build`，输出静态资源用于部署。

## 验证方式（AC-01）

AC-01 涉及每秒定时更新，属于定时任务路径：

- 时间格式（`HH:MM:SS` 两位补零）可由组件渲染输出直接确定性地验证。
- 实时性验证：打开页面后观察显示值与系统时钟一致，并在连续数秒内每秒变化一次；可通过将定时器间隔在测试环境下临时缩短或断言两次渲染间隔来确认更新逻辑生效。
- 初态恢复：无需恢复，页面状态仅依赖系统时钟，无累积或持久状态。

## 边界

不引入服务端 API、数据库、认证、后台任务、外部服务集成或跨设备/跨用户数据同步。所有行为在浏览器端完成。
