# 贪吃蛇游戏 — 架构基线

> 本文档基于已批准的需求基线 `docs/wi-t1000054/requirements.md`（sha256:a9abec4636b2b1cb58cd6d362bf515c873a34088b34d281171e24b5de6a25496），仅描述技术承载方式，不扩展或重裁产品语义。

## 1. 应用类型与路线

- **类型**：简单前端 SPA（React + Vite）
- **路线**：`simple-frontend`（compact）
- **理由**：需求描述的全部行为——网格移动、方向控制、吃食物增长、碰撞结束、得分显示、重启——均在浏览器界面内完成，无需服务端权威数据、认证、后台任务、外部集成或跨设备数据共享。

## 2. 页面与交互范围

单页面承载完整游戏体验，包含以下可视区域和交互入口：

| 区域 | 说明 |
|------|------|
| 游戏画布 | Canvas 或网格 DOM 渲染游戏区域，显示蛇、食物、边界 |
| 得分显示 | 实时显示当前得分；游戏结束时展示最终得分 |
| 方向控制 | 键盘方向键（↑↓←→）控制蛇头行进方向；不支持 180° 反向调头 |
| 开始/重启 | 游戏结束后的重新开始入口 |

## 3. 浏览器状态与数据归属

- **游戏状态**：全部运行在浏览器内存中（React 组件 state / ref），包括蛇身坐标队列、当前方向、食物位置、得分、游戏状态（进行中/结束）。
- **持久化**：当前需求基线不要求任何数据持久化。页面刷新后游戏回到初始状态，不在 `localStorage` 或其他存储中保留任何数据。
- **数据边界**：所有数据仅存在于当前浏览器会话内存中，不与其他浏览器、设备或用户共享。

## 4. 实现入口与运行方式

- **技术栈**：React 18 + TypeScript + Vite
- **项目入口**：`index.html` → `src/main.tsx` → `src/App.tsx`
- **游戏核心**：`src/App.tsx` 承载游戏循环、状态管理和渲染逻辑；可按职责拆分为游戏 hook 和渲染组件，但保持单应用结构。
- **运行方式**：Vite 开发服务器，`npm run dev` 启动本地开发环境；`npm run build` 生成生产构建。

## 5. 核心技术决策

| 决策 | 选择 | 说明 |
|------|------|------|
| 渲染方式 | HTML Canvas 2D | 网格游戏适合 Canvas 像素级渲染，性能优于频繁 DOM 更新 |
| 游戏循环 | `requestAnimationFrame` + 时间步控制 | 按固定间隔（tick）推进蛇移动，保证速度稳定 |
| 网格规模 | 20×20 格（默认） | 固定网格，边界即游戏结束区域 |
| 方向控制 | 键盘事件监听 + 方向队列 | 防止快速连按导致反向调头；每 tick 只消费一个方向输入 |
| 食物生成 | 随机选取空格子 | 从当前非蛇身格子集合中均匀随机选取 |
| 碰撞检测 | 坐标比较 | 蛇头坐标与边界/蛇身坐标集合比对 |

## 6. 可重复验证方式

本游戏的验收涉及自动推进（蛇持续移动）、随机结果（食物位置）和动画（定时渲染），以下方式确保验收可重复执行：

**受影响的 AC：AC-01（移动与吃食物）、AC-02（碰撞结束）**

| AC | 随机/时序因素 | 可重复验证方式 |
|----|-------------|--------------|
| AC-01 | 蛇自动移动、食物随机生成 | 渲染初始状态后，通过测试控制入口单步推进游戏 tick（不依赖实时定时器），将食物固定到已知格子，验证蛇移动到该格子后身体增长且得分增加 |
| AC-02 | 蛇自动移动 | 通过测试控制入口单步推进蛇朝边界或自身方向移动，验证碰撞后游戏状态切换为结束、蛇停止移动、最终得分正确显示 |
| AC-03 | 无特殊时序因素 | 直接交互验证：触发重启后检查蛇位置、方向、得分、食物是否重置为初始状态 |

**测试控制入口（仅测试环境使用）**：

- `__snakeTest.step()`: 单步推进一个游戏 tick，不等待实时定时器
- `__snakeTest.setFood(x, y)`: 将下一个食物固定到指定格子，覆盖随机生成
- `__snakeTest.getState()`: 读取当前游戏状态快照（蛇身坐标、方向、得分、状态、食物位置）

这些入口仅在测试/开发环境下挂载到 `window` 对象；生产构建中不暴露。正常运行时游戏按产品要求的固定速度和随机食物执行，不受测试入口影响。

## 7. 边界与不包含

本设计不包含以下内容（与需求基线一致）：

- 无服务端、API、数据库或认证
- 无后台任务或外部服务集成
- 无跨用户/跨设备数据同步
- 无多人模式
- 无最高分持久化记录
- 无难度调节或等级系统
