# 贪吃蛇游戏需求文档

## 1. 目标

开发一个可玩的贪吃蛇游戏：玩家操控蛇在网格区域内移动，吃食物增长身体，避免撞墙或撞自身，追求尽可能高的分数。

**用户明确提出**：开发一个贪吃蛇游戏。
**未规定**：具体平台/技术栈、视觉风格、难度曲线、最高分记录方式、多人模式。这些不纳入当前基线，不生成正式 AC。

## 2. 核心行为与规则

### 2.1 游戏区域

- 游戏在一个固定大小的网格区域内进行。
- 网格区域有边界，蛇撞到边界时游戏结束。

### 2.2 蛇的移动

- 蛇由头部和身体节段组成，在网格上连续移动。
- 蛇按固定速度持续移动，玩家通过方向输入改变蛇头的行进方向。
- 方向输入支持上、下、左、右四个方向；不支持直接反向（180°）调头，即当前向右移动时不能直接向左转。
- 蛇头进入新格子后，身体节段依次跟随头部轨迹移动。

### 2.3 食物与增长

- 网格内同时只存在一个食物，位于随机空格子中。
- 蛇头碰到食物格子时：蛇身体增长一节、当前得分增加、在剩余空格子中重新生成下一个食物。
- 若网格已无空格子（蛇填满整个区域），游戏胜利结束。

### 2.4 碰撞与结束

- 蛇头碰到边界 → 游戏结束（失败）。
- 蛇头碰到自身身体节段 → 游戏结束（失败）。
- 蛇填满整个网格区域 → 游戏结束（胜利）。

### 2.5 得分

- 每吃一个食物得分 +1（或等量分值），实时显示当前得分。
- 游戏结束后显示最终得分。

### 2.6 游戏状态流转

- **开始**：页面加载或用户触发"开始"后，蛇从初始位置以初始方向开始移动。
- **进行中**：蛇持续移动，玩家实时输入方向控制。
- **结束**：触发碰撞或胜利条件后，停止移动，展示结束信息与最终得分，提供重新开始的方式。

## 3. 验收场景

### AC-01：玩家可操控蛇移动并吃食物增长得分
- 验收条件：蛇能持续移动，玩家可通过方向输入改变蛇的行进方向，吃到食物后蛇身体增长且得分增加。
- 入口类型：用户界面
- 验证动作：启动游戏，使用方向控制让蛇朝食物方向移动并吃到食物。
- 预期结果：吃到食物后蛇身体增长一节，得分增加，网格内出现新的食物。
- 证据类型：runtime-render, interaction

### AC-02：蛇撞墙或撞自身时游戏结束并显示最终得分
- 验收条件：蛇头碰到边界或自身身体时游戏结束，显示结束状态与最终得分，蛇停止移动。
- 入口类型：用户界面
- 验证动作：启动游戏，操控蛇撞向边界（或绕圈撞向自身）。
- 预期结果：游戏立即结束，画面展示结束信息与最终得分，蛇不再移动。
- 证据类型：runtime-render, interaction

### AC-03：游戏结束后可重新开始
- 验收条件：游戏结束后，玩家可通过操作重新开始一局新游戏，新一局开始时蛇、得分和食物重置为初始状态。
- 入口类型：用户界面
- 验证动作：触发游戏结束后，使用提供的重新开始操作启动新一局。
- 预期结果：蛇回到初始位置和初始方向，得分归零，网格内出现初始食物，蛇开始移动。
- 证据类型：runtime-render, interaction
