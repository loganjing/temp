# 教师管理系统需求

## 目标

提供一个教师管理系统，支持对教师信息的增删改查操作。

## 字段定义

| 字段 | 说明 | 来源 |
|------|------|------|
| 教师名称 | 教师的姓名 | 用户明确提出 |
| 教授课程 | 教师所教授的课程 | 用户明确提出 |
| 年级 | 教师所负责的年级 | 用户明确提出 |
| 手机 | 教师的手机号码 | 用户明确提出 |
| 邮箱 | 教师的电子邮箱 | 用户明确提出 |

## 功能需求

### 教师列表

- 用户可查看所有已创建的教师记录列表，列表中展示教师名称、教授课程、年级、手机、邮箱信息。

### 新增教师

- 用户可通过新增功能填写教师名称、教授课程、年级、手机、邮箱字段并保存。
- 保存成功后，该教师记录出现在教师列表中。

### 编辑教师

- 用户可对已有教师记录进行编辑，修改任意字段后保存。
- 保存成功后，列表中该记录显示更新后的信息。

### 删除教师

- 用户可删除已有的教师记录。
- 删除成功后，该记录不再出现在教师列表中。

## 验收场景

### AC-01：新增教师后记录可在列表中查看
- 验收条件：用户填写教师信息并保存后，该记录出现在教师列表中。
- 入口类型：用户界面
- 验证动作：在新增教师入口填写教师名称、教授课程、年级、手机、邮箱，保存后返回教师列表。
- 预期结果：列表中显示刚创建的教师记录，包含全部已填写字段值。
- 证据类型：interaction,session-persistence

### AC-02：教师列表展示已有记录
- 验收条件：教师列表展示所有已创建的教师记录及其字段信息。
- 入口类型：用户界面
- 验证动作：在已存在多条教师记录的状态下打开教师列表。
- 预期结果：列表中展示所有教师记录，每条记录包含教师名称、教授课程、年级、手机、邮箱。
- 证据类型：runtime-render

### AC-03：编辑教师后修改结果可在列表中查看
- 验收条件：用户修改已有教师记录字段并保存后，列表中该记录显示更新后的值。
- 入口类型：用户界面
- 验证动作：选择一条已有教师记录，修改其中一个或多个字段值并保存，返回教师列表。
- 预期结果：列表中该记录显示修改后的字段值，其他记录不受影响。
- 证据类型：interaction,session-persistence

### AC-04：删除教师后记录不再出现在列表中
- 验收条件：用户删除一条教师记录后，该记录不再出现在教师列表中。
- 入口类型：用户界面
- 验证动作：选择一条已有教师记录，执行删除操作，返回教师列表。
- 预期结果：列表中不再包含被删除的教师记录，其他记录不受影响。
- 证据类型：interaction,session-persistence
