# 教师管理系统 — 需求规格

## 1. 概述

### 1.1 业务目标

为学校提供一套教师管理功能，支持对教师信息进行新增、查看、编辑和删除（增删改查），便于教务人员维护教师基础档案。

### 1.2 范围

- **纳入范围**：教师信息列表展示、新增教师、编辑教师信息、删除教师、字段校验。
- **非目标**：用户登录与权限管理、多角色协作、课程排课、班级管理、数据导入导出、服务端持久化（本阶段不要求）。

### 1.3 用户角色

| 角色 | 说明 |
|---|---|
| 教务管理员 | 负责录入、修改、删除教师信息，查看教师列表 |

---

## 2. 数据对象

### 2.1 教师信息（Teacher）

| 序号 | 字段名称 | 字段标识 | 类型 | 必填 | 说明 |
|---|---|---|---|---|---|
| 1 | 教师名称 | name | 文本 | 是 | 教师姓名，不超过 50 字符 |
| 2 | 教授课程 | course | 文本 | 是 | 教师教授的课程名称，如"数学"、"语文" |
| 3 | 年级 | grade | 文本 | 是 | 教师所带年级，如"一年级"、"高三" |
| 4 | 手机 | phone | 文本 | 是 | 手机号码，需符合中国大陆手机号格式（11 位数字，以 1 开头） |
| 5 | 邮箱 | email | 文本 | 否 | 电子邮箱地址，需符合标准邮箱格式 |

---

## 3. 功能需求

### 3.1 教师列表（查看）

**前置条件**：系统中已有教师数据（或为空列表）。

**主流程**：
1. 教务管理员进入教师管理页面
2. 系统以列表/表格形式展示所有教师信息，包含：教师名称、教授课程、年级、手机、邮箱
3. 列表支持查看每条教师记录的完整字段

**验收标准**：
- AC-1：页面加载后展示教师列表，包含全部 5 个字段列
- AC-2：无数据时显示空状态提示
- AC-3：列表按创建时间倒序排列

### 3.2 新增教师

**前置条件**：教务管理员在教师管理页面。

**主流程**：
1. 点击"新增教师"按钮
2. 弹出/跳转到新增表单，包含：教师名称、教授课程、年级、手机、邮箱
3. 填写各项信息后点击"保存"
4. 校验通过后，教师信息保存成功，列表自动刷新并显示新增记录

**异常流程**：
- 必填字段为空时，提示对应字段不能为空
- 手机号格式不正确时，提示"请输入正确的手机号码"
- 邮箱格式不正确时，提示"请输入正确的邮箱地址"

**验收标准**：
- AC-4：点击新增按钮后出现包含 5 个字段的录入表单
- AC-5：必填字段（教师名称、教授课程、年级、手机）为空时无法保存并给出提示
- AC-6：手机号格式校验：非 11 位数字或非 1 开头时拒绝保存
- AC-7：邮箱格式校验：填写邮箱时格式不正确拒绝保存；留空时允许保存
- AC-8：保存成功后教师出现在列表中

### 3.3 编辑教师

**前置条件**：列表中存在教师记录。

**主流程**：
1. 在列表中对某条教师记录点击"编辑"
2. 弹出/跳转到编辑表单，表单回填该教师当前信息
3. 修改字段后点击"保存"
4. 校验通过后，信息更新成功，列表刷新显示最新数据

**异常流程**：
- 同新增的校验规则

**验收标准**：
- AC-9：编辑表单回填当前教师信息
- AC-10：修改后保存成功，列表中该记录信息更新
- AC-11：编辑时同样执行必填与格式校验

### 3.4 删除教师

**前置条件**：列表中存在教师记录。

**主流程**：
1. 在列表中对某条教师记录点击"删除"
2. 弹出确认提示"确定删除该教师吗？"
3. 点击"确认"后，该教师记录从列表中移除

**异常流程**：
- 点击"取消"则不执行删除

**验收标准**：
- AC-12：点击删除后出现确认提示
- AC-13：确认删除后记录从列表中消失
- AC-14：取消删除后记录保留不变

---

## 4. 业务规则

| 编号 | 规则 | 说明 |
|---|---|---|
| BR-1 | 教师名称唯一性 | 同名教师允许存在（不做唯一性约束） |
| BR-2 | 手机号格式 | 中国大陆手机号：11 位数字，以 1 开头 |
| BR-3 | 邮箱格式 | 标准邮箱格式（如 `user@example.com`），选填 |
| BR-4 | 数据持久化 | 本阶段使用浏览器本地存储（localStorage）持久化，刷新页面后数据不丢失 |

---

## 5. 待决项

无。用户需求中字段和增删改查操作已明确，无内部矛盾或需用户裁决的业务选择。
