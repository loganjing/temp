# k12-clock 架构基线

## 设计依据

本设计基于已批准的需求快照 `docs/wi-t1000050/requirements.md`（sha256: 2df7a31c204b3597b6b11f17d710c58124cd4a3dd974349e18f12e08375eed82），不扩展或重裁其产品语义。

- 路线：`simple-frontend`（compact）。需求仅要求单个页面展示当前时分秒，时间来源为客户端系统时间，无服务端权威数据、认证、后台任务、外部集成或跨设备/跨用户共享数据。
- 数据归属：无持久化数据。时间显示为浏览器运行期间的瞬时值，由客户端系统时钟派生，关闭页面即停止更新。

## 页面与交互范围

- 单页面，承载唯一行为：展示当前时、分、秒。
- 显示格式：`HH:MM:SS`（24 小时制，两位补零）。
- 实时更新：每秒刷新一次显示，与客户端系统时间保持同步。
- 时间来源：浏览器 `Date` 对象读取本机系统时间；不依赖任何服务端或外部时间源。
- 更新机制：使用浏览器定时器（`setInterval`，1 秒间隔）驱动重渲染；页面卸载时清理定时器以避免泄漏。

## 技术选型与实现入口

- 新建 React/Vite SPA（单页应用），满足需求未规定技术选型的默认基线。
- 视觉方向：极简数字时钟风格。本项目不属于管理工作台类应用，不引入 Ant Design 等工作台 UI 体系；使用原生 CSS 实现清晰、可读的大号数字时钟显示，配色与字体大小在实现阶段确定，保持约束在“可读、居中、单页”范围内。
- 实现入口（新建 Vite 应用）：
  - 开发运行：`npm run dev`（Vite 开发服务器）。
  - 生产构建：`npm run build`。
  - 核心组件：一个时钟组件，挂载时启动 1 秒定时器，每秒读取系统时间并更新 `HH:MM:SS` 显示，卸载时清理定时器。
- 不虚构服务/API、数据库、认证、后台任务、外部集成或同步层。

## 验收映射

- AC-01（页面实时显示当前时分秒）：
  - 确定性部分：打开页面即可读取系统时间并按 `HH:MM:SS` 渲染，格式与补零规则可由渲染输出直接验证。
  - 实时部分：需在运行时观察显示值是否随系统时间每秒推进，与设备/系统时间一致；无随机结果或异步外部事件，验证不要求额外的测试控制入口。
  - 无持久化或共享状态，验证无需预置或恢复状态。
