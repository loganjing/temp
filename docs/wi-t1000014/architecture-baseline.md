# 架构基线：实时时钟页面

> Work Item: wi-t1000014 | 业务任务: 152-clock

## 需求基线引用

本设计基于已批准的需求文档 `docs/wi-t1000014/requirements.md`（SHA-256: `be9c149ca6801997dfda387742403dbbd6ecfa13b3d437168c2a0e3916f8e82a`）。

## 应用分类

- **路线**: simple-frontend（精简前端）
- **理由**: 需求仅要求页面实时显示当前时:分:秒，时间来源为浏览器系统时钟。无需服务端权威数据、认证、后台任务、外部服务集成或跨用户/设备数据共享。

## 页面与交互范围

- 单页面应用，展示一个实时时钟，以 `HH:MM:SS` 格式显示当前系统时间。
- 页面加载后立即显示当前时间，并通过客户端定时器每秒更新，秒位持续递增，用户无需手动刷新。
- 无用户输入、无数据持久化、无路由跳转——页面只有一个只读的时间展示视图。

## 浏览器状态与数据归属

- 时间数据来源于浏览器 `Date` API（`new Date()`），反映用户设备的本地系统时间。
- 不使用 `localStorage` 或任何客户端存储——时钟无需在刷新后保留状态，刷新后重新从系统时钟读取即可。
- 不涉及跨浏览器、跨设备或跨用户的数据共享。

## 实现入口与运行方式

- 新建 React/Vite SPA 应用。
- 实现入口：Vite 开发服务器，通过 `npm run dev` 启动。
- 核心组件：一个 Clock 组件，在 `useEffect` 中通过 `setInterval` 每秒调用 `setState` 更新时间字符串，组件卸载时清除定时器。
- 时间格式化：使用 `Date.prototype.toLocaleTimeString` 或手动拼接 `时:分:秒`，保证两位数显示。

## 技术边界

- 不引入服务端 API、数据库、认证、后台任务或外部服务集成。
- 不生成 `technical-contract.md`、`workspace-bootstrap.json`、ADR 或实现计划。
- 本架构仅承载需求基线中已冻结的产品语义，不扩展或重裁验收场景与业务规则。
