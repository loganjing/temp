# 157-ticket 工单系统需求文档

## 1. 目标与范围

### 1.1 目标

构建一个面向多公司的工单管理系统，支持工单全生命周期管理、按分类自动分配到业务组、工单转派协作、处理完成邮件通知、用户满意度评价和运营统计分析，并提供工单工作台供处理人高效处理待办工单。

### 1.2 范围

涵盖工单创建与管理、工单分配（业务组与自动分配规则）、工单协作（转派）、工单处理（提交人信息查看、处理记录、邮件通知）、用户评价、统计分析（分布统计与运营仪表盘）、工单工作台和操作日志记录。

## 2. 角色与参与方

以下角色由用户描述的工单流程中的操作行为推导得出：

| 角色 | 说明 |
|------|------|
| 提交人 | 创建工单，接收工单完成邮件通知，对已完成工单进行满意度评价 |
| 处理人 | 被分配到业务组的成员，接收并处理工单，进行多轮回复 |
| 管理员 | 配置公司的业务组与成员，设置分类到业务组的自动分配规则 |

## 3. 工单生命周期

工单具有以下状态 [用户明确提出]：

| 状态 | 说明 |
|------|------|
| 创建 | 工单提交后的初始状态 |
| 待分配 | 工单已提交，等待分配到业务组或处理人 |
| 待处理 | 工单已分配，等待处理人处理 |
| 完成 | 工单处理结束 |
| 取消 | 工单被取消，为终态 |

状态流转路径：

```
创建 → 待分配 → 待处理 → 完成
                  ↓
                取消
```

- 工单在待分配、待处理状态下可被取消 [推荐基线，用户仅明确"取消"为状态，未规定可取消的状态范围]。

## 4. 业务规则与模块需求

### 4.1 工单管理

**工单基本信息** [用户明确提出]：
- 工单包含以下字段：工单 ID、主题、描述、分类、提交人信息（含邮箱）、创建时间。
- 工单按公司隔离：工单归属于提交人所在公司，不同公司之间的工单数据不可见。
- 支持 SLA 优先级设置，优先级范围为 P0–P4。
- 支持问题分类，分类用于工单归类和自动分配。

**多轮回复** [用户明确提出]：
- 工单支持多轮回复，每条回复记录回复人和回复时间。
- 回复按时间顺序排列，提交人和处理人均可回复。

### 4.2 工单分配

**业务组管理** [用户明确提出]：
- 允许给某个公司增加多个业务组。
- 每个业务组可以设置成员（即处理人）。
- 业务组归属于特定公司，不同公司的业务组相互隔离。

**自动分配规则** [用户明确提出]：
- 允许配置某个公司的工单按照分类自动分配到某个业务组。
- 分配规则维度为公司 + 分类 → 业务组。
- 工单创建后，系统根据工单的公司和分类匹配分配规则，将工单分配到对应的业务组，状态从待分配流转到待处理 [推荐基线：自动分配匹配到规则时直接进入待处理；未匹配到规则时停留在待分配，等待手动分配]。

### 4.3 工单协作

**工单转派** [用户明确提出]：
- 支持工单转派操作：当前处理人可将工单转派给其他处理人或业务组。
- 转派后工单仍处于待处理状态，由新的处理人接手。
- 转派操作需记录操作人、转派目标和转派时间 [推荐基线，用户未明确要求记录转派详情，但日志模块要求记录相关日志]。

### 4.4 工单处理

**提交人信息查看** [用户明确提出]：
- 在处理工单时，处理人可查看提交人的完整信息，包括：姓名、公司、部门、历史工单。
- 历史工单展示该提交人此前提交的工单列表。

**处理记录与完成通知** [用户明确提出]：
- 工单处理后，记录处理人和处理时间。
- 工单完成时，向提交人发送邮件通知。
- 邮件发送到提交人信息中记录的邮箱地址。

### 4.5 用户评价

**满意度评价** [用户明确提出]：
- 用户收到完成的工单后，可对工单进行满意度评价。
- 满意度评价为用户对工单处理结果的反馈。

### 4.6 统计分析

**工单分布统计** [用户明确提出]：
- 支持按公司维度统计工单分布。
- 支持按部门维度统计工单分布。

**运营仪表盘** [用户明确提出]：
- 提供统计与分析仪表盘，查看以下运营指标：
  - 工单量
  - 平均响应时间
  - 满意度
  - 热点问题

### 4.7 工单工作台

**工作台功能** [用户明确提出]：
- 查看待处理工单列表。
- 支持筛选、搜索、排序。
- 可按公司维度筛选。

### 4.8 日志记录

**操作日志** [用户明确提出]：
- 记录工单相关的操作日志。
- 涵盖工单生命周期中的关键操作：创建、分配、转派、处理、完成、取消等 [推荐基线，用户仅明确"记录相关日志"，具体记录哪些操作为推荐]。

## 5. 验收场景

### AC-01：工单创建、公司隔离、SLA 优先级与生命周期状态

- 验收条件：提交人可创建包含完整字段的工单，工单按公司隔离，可设置 SLA 优先级（P0–P4）和问题分类，工单在生命周期状态间正确流转。
- 入口类型：用户界面
- 验证动作：提交人在工单创建入口填写主题、描述、分类等信息并提交工单；分别验证工单从待分配到待处理、到完成的状态流转，以及取消操作。
- 预期结果：
  - 工单创建成功，包含工单 ID、主题、描述、分类、提交人信息（含邮箱）、创建时间；
  - 工单可设置 SLA 优先级 P0–P4；
  - 不同公司的用户无法看到对方的工单；
  - 工单状态按创建→待分配→待处理→完成流转，取消可将工单置为取消终态。
- 证据类型：interaction, runtime-render, session-persistence

### AC-02：工单多轮回复

- 验收条件：工单支持多轮回复，每条回复记录回复人和回复时间，回复按时间顺序展示。
- 入口类型：用户界面
- 验证动作：在已创建的工单中，提交人和处理人分别多次回复。
- 预期结果：
  - 每条回复记录回复人和回复时间；
  - 回复按时间顺序排列；
  - 支持多轮回复，无轮数限制。
- 证据类型：interaction, runtime-render

### AC-03：业务组管理与按分类自动分配

- 验收条件：管理员可为公司创建多个业务组并设置成员，配置分类到业务组的自动分配规则，工单创建后根据公司与分类自动分配到对应业务组。
- 入口类型：用户界面
- 验证动作：管理员为某公司创建业务组并添加成员，配置该公司的分类→业务组分配规则；提交人创建该分类的工单。
- 预期结果：
  - 业务组创建成功，成员可添加；
  - 工单创建后，系统根据公司+分类匹配规则，将工单分配到对应业务组，状态从待分配变为待处理；
  - 未配置规则的分类工单停留在待分配状态。
- 证据类型：interaction, runtime-render, session-persistence

### AC-04：工单转派

- 验收条件：处理人可将工单转派给其他处理人或业务组，转派后工单由新处理人接手。
- 入口类型：用户界面
- 验证动作：处理人在待处理工单中执行转派操作，选择目标处理人或业务组。
- 预期结果：
  - 转派操作成功，工单分配给新的处理人或业务组；
  - 工单仍处于待处理状态；
  - 新处理人可在工作台看到该工单。
- 证据类型：interaction, runtime-render

### AC-05：工单处理——提交人信息查看、处理记录与邮件通知

- 验收条件：处理人在处理工单时可查看提交人完整信息（姓名、公司、部门、历史工单），工单完成后记录处理人和处理时间，并向提交人发送邮件通知。
- 入口类型：用户界面
- 验证动作：处理人打开待处理工单，查看提交人信息面板；完成工单处理并标记完成。
- 预期结果：
  - 处理人可查看提交人姓名、公司、部门和历史工单列表；
  - 工单完成后记录处理人和处理时间；
  - 提交人邮箱收到工单完成通知邮件。
- 证据类型：interaction, runtime-render

### AC-06：用户满意度评价

- 验收条件：用户在工单完成后可对工单进行满意度评价。
- 入口类型：用户界面
- 验证动作：提交人在已完成的工单中进行满意度评价。
- 预期结果：
  - 评价操作成功并记录；
  - 评价结果可在工单中查看。
- 证据类型：interaction, runtime-render

### AC-07：按公司与部门维度统计工单分布

- 验收条件：系统支持按公司维度和部门维度统计工单分布。
- 入口类型：用户界面
- 验证动作：在统计分析入口分别按公司维度和部门维度查看工单分布。
- 预期结果：
  - 按公司维度展示各公司的工单分布数据；
  - 按部门维度展示各部门的工单分布数据。
- 证据类型：runtime-render

### AC-08：运营仪表盘展示工单运营指标

- 验收条件：统计与分析仪表盘展示工单量、平均响应时间、满意度和热点问题等运营指标。
- 入口类型：用户界面
- 验证动作：打开运营仪表盘页面。
- 预期结果：
  - 仪表盘展示工单量、平均响应时间、满意度、热点问题指标；
  - 指标数据基于实际工单数据计算。
- 证据类型：runtime-render

### AC-09：工单工作台筛选、搜索与排序

- 验收条件：工单工作台展示待处理工单列表，支持筛选、搜索、排序，可按公司维度筛选。
- 入口类型：用户界面
- 验证动作：处理人打开工单工作台，使用筛选（含公司维度）、搜索和排序功能。
- 预期结果：
  - 待处理工单列表正确展示；
  - 筛选（含按公司）可缩小列表范围；
  - 搜索可按关键词匹配工单；
  - 排序可按指定字段重新排列列表。
- 证据类型：interaction, runtime-render

### AC-10：工单操作日志记录

- 验收条件：系统记录工单相关的操作日志，涵盖创建、分配、转派、处理、完成、取消等关键操作。
- 入口类型：内部
- 验证动作：执行工单创建、分配、转派、处理、完成、取消操作后，查看操作日志。
- 预期结果：
  - 各关键操作均有对应的日志记录；
  - 日志包含操作类型和操作时间。
- 证据类型：runtime-render
