# 需求文档：日常专注时段记录系统

> Work Item: wi-t1000085 | IssueTask: T1000085

## 1. 目标

为用户提供一个单页面应用，内置番茄钟倒计时，在专注时段结束后自动记录到当日列表，并在页面上方展示累计专注时长、下方展示当日各时段专注热力图，帮助用户了解自己一天的专注分布。

## 2. 用户明确提出的需求

| # | 用户原述 | 说明 |
|---|---------|------|
| R1 | 单页面 | 所有功能集中在同一页面，无需多页面跳转 |
| R2 | 内置番茄钟倒计时（25 分钟专注 + 5 分钟休息） | 倒计时从 25:00 计至 00:00 表示一段专注结束，随后进入 5 分钟休息倒计时 |
| R3 | 每次完成一个番茄钟自动记录到当日列表 | 专注时段倒计时归零后，系统自动生成一条当日记录，无需手动操作 |
| R4 | 页面上方显示累计专注时长 | 汇总当日已完成专注时段的总时长 |
| R5 | 下方展示当日各时段专注热力图 | 以热力图形式可视化当日每个时段的专注强度 |

## 3. 核心行为与规则

### 3.1 番茄钟倒计时（R2，用户明确）

- 页面提供番茄钟倒计时控件，默认显示 25:00 并可由用户启动。
- 专注阶段：从 25:00 递减至 00:00。
- 休息阶段：专注阶段归零后自动进入 5 分钟休息倒计时（05:00 → 00:00）。
- 用户可启动倒计时；倒计时运行过程中可暂停和恢复。（推荐基线：暂停后恢复从暂停时刻继续，不重置时长。）

### 3.2 自动记录（R3，用户明确）

- 当专注阶段倒计时自然归零（非手动停止）时，系统自动将本次专注时段记录到当日列表。
- 每条记录至少包含：完成时刻、专注时长（25 分钟）。
- 手动暂停或中止的专注时段不生成记录。（推荐基线）

### 3.3 累计专注时长（R4，用户明确）

- 页面上方区域实时展示当日所有已完成专注时段的总时长。
- 每次新增记录后，累计时长同步更新。

### 3.4 当日热力图（R5，用户明确）

- 页面下方区域以热力图形式展示当日各时段的专注分布。
- 热力图将一天划分为若干时段，每个时段根据该时段内完成的专注次数以不同强度（颜色深浅）呈现。
- 无专注记录的时段以最低强度显示。

### 3.5 单页面约束（R1，用户明确）

- 倒计时控件、累计专注时长、当日记录列表、热力图均在同一页面内呈现，无需页面跳转。

## 4. 推荐基线

| # | 推荐项 | 理由 | 可逆性 |
|---|--------|------|--------|
| RB1 | 倒计时运行中可暂停与恢复 | 用户可能被临时打断，暂停后恢复比强制重来更合理；不影响核心 25+5 周期规则 | 可逆，用户可改为只支持启动/重置 |
| RB2 | 手动中止的专注时段不生成记录 | "完成一个番茄钟"应指自然完成；避免不完整时段污染统计 | 可逆 |
| RB3 | 当日记录在当前浏览器会话内保持 | "记录"的基本语义要求至少在页面未关闭时数据不丢失；刷新页面后是否保留未规定 | 可逆，可扩展为跨会话持久化 |

## 5. 未规定事项

- 休息结束后是否自动开始下一段专注：未规定。
- 热力图具体时段划分粒度（如按小时、按半小时）：未规定，由实现决定。
- 跨日数据保留与历史查询：未规定。
- 数据存储方式与技术：未规定。
- 用户账户与多设备同步：未规定。
- 专注时段标签或任务描述：未规定。

## 6. 验收场景

### AC-01：番茄钟倒计时完成一个专注+休息周期

- 验收条件：用户启动番茄钟后，专注阶段从 25:00 递减至 00:00，随后自动进入 5 分钟休息倒计时。
- 入口类型：用户界面
- 验证动作：启动番茄钟倒计时，观察专注阶段倒计时递减并归零。
- 预期结果：专注阶段倒计时归零后，页面自动切换到 5 分钟休息倒计时。
- 证据类型：interaction,runtime-render

### AC-02：完成专注时段后自动记录并更新累计时长

- 验收条件：专注阶段自然归零后，当日列表新增一条记录，页面上方累计专注时长同步增加。
- 入口类型：用户界面
- 验证动作：等待一段专注阶段倒计时自然归零（可使用加速方式触发），观察当日列表和页面上方累计区域。
- 预期结果：当日列表新增一条包含完成时刻和专注时长的记录；累计专注时长增加对应的专注时长。
- 证据类型：interaction,runtime-render

### AC-03：当日各时段专注热力图展示

- 验收条件：页面下方热力图根据当日已完成的专注时段记录，以不同强度显示各时段的专注分布。
- 入口类型：用户界面
- 验证动作：在当日列表已有至少一条记录的状态下，查看页面下方热力图区域。
- 预期结果：热力图中包含已完成专注时段对应的时段区块，其强度高于无记录时段；无记录时段以最低强度显示。
- 证据类型：runtime-render,visual-style

### AC-04：单页面集成

- 验收条件：番茄钟倒计时控件、累计专注时长、当日记录列表、热力图均在同一页面内呈现，无需跳转。
- 入口类型：用户界面
- 验证动作：打开应用页面，在同一视图中确认上述四个区域同时可见。
- 预期结果：四个区域（倒计时、累计时长、当日列表、热力图）在同一页面内呈现，操作过程中无需跳转到其他页面。
- 证据类型：runtime-render,visual-style
