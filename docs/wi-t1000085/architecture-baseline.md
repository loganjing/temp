# 架构基线：日常专注时段记录系统

> Work Item: wi-t1000085 | IssueTask: T1000085 | 路线: simple-frontend（compact）

本基线依据已批准的需求快照 `docs/wi-t1000085/requirements.md`（sha256: 33363d8e398cd8f3624d554b761e28e8a41f17318341d3cd39a02e7d77e31c0c）编写，仅描述必要的技术承载方式，不改变产品语义、不重裁验收场景。

## 1. 应用类型与数据归属

- **类型**：单页面应用（SPA），纯前端，无服务端。
- **数据归属**：当日专注记录存入浏览器 `localStorage`，数据仅在同一浏览器配置文件中刷新或重新打开后保留；不与其他浏览器、设备或用户共享。不提供账户、认证、跨设备同步。
- **技术栈**：React + Vite + TypeScript。UI 组件默认采用 Ant Design（`antd` 与 `@ant-design/icons`）。视觉方向：浅色工作区、顶部上下文标题与主操作，倒计时控件居中突出，累计时长与记录列表为白色表面卡片，热力图以行/列网格呈现强度色阶。

## 2. 页面与交互范围

所有功能集中于同一页面，自上而下分为四个区域，无需页面跳转：

1. **累计专注时长区（顶部）**：实时汇总当日已完成专注时段总时长（分钟），新增记录后同步更新。
2. **番茄钟倒计时控件（中部）**：默认显示 `25:00`，可启动、暂停、恢复。专注阶段（25:00 → 00:00）自然归零后自动进入休息阶段（05:00 → 00:00）。休息归零后回到专注待启动状态。
3. **当日记录列表（中下部）**：专注阶段自然归零时自动新增一条记录，含完成时刻与专注时长（25 分钟）；手动暂停/中止不生成记录。
4. **当日热力图（底部）**：将一天划分为时段（基线按半小时划分 48 格），每个时段依据该时段内完成的专注次数以强度色阶呈现，无记录时段以最低强度显示。

## 3. 状态与数据模型

- **番茄钟状态机**：`idle` → `focusing` → `resting` → `idle`（休息后回到待启动）。`focusing` 支持暂停/恢复；暂停恢复从暂停时刻继续，不重置时长。
- **当日记录**：`{ id: string; completedAt: ISO-8601 本地时刻; durationMinutes: 25 }`，按完成时刻升序存储于 `localStorage` 键 `focus-records-YYYY-MM-DD`（按本地日期分区）。
- **累计时长**：由当日记录派生（`sum(durationMinutes)`），不单独持久化。
- **热力图**：由当日记录按完成时刻归入对应半小时时段聚合（每时段专注次数）派生，不单独持久化。

## 4. 实现入口与运行方式

- **入口**：Vite SPA，开发服务器 `npm run dev`，构建 `npm run build`。
- **时钟实现**：使用 `setInterval`（1 秒 tick）驱动倒计时显示与阶段切换；专注阶段自然归零触发记录写入与休息阶段进入。不使用 Web Worker 或服务端计时。
- **持久化时机**：仅在专注阶段自然归零时写入 `localStorage`；暂停/中止不写入。

## 5. 验收可重复验证说明

本应用验收涉及定时器（AC-01、AC-02），25 分钟专注 + 5 分钟休息周期在常规验证中不可等待。为支持可重复验证，提供最小测试控制入口（仅测试环境使用，正常运行仍按产品要求执行）：

- **测试控制入口**：在查询参数 `?test=1` 下，将专注阶段时长压缩为可配置短时长（基线 5 秒）、休息阶段为 2 秒，并通过 `window.__focusDebug__` 暴露 `setDurations({focusSeconds, restSeconds})`、`skipToFocusEnd()`、`clearTodayRecords()` 方法。
- **AC-01**：在 `?test=1` 下启动倒计时，观察专注阶段递减并归零后自动切换到休息倒计时；可由 `skipToFocusEnd()` 直接推进到专注归零边界验证阶段切换。
- **AC-02**：在 `?test=1` 下用短时长自然走完专注阶段，断言当日列表新增一条记录且累计时长增加 25（产品语义时长不变）；`clearTodayRecords()` 用于恢复初态。
- **AC-03**：预置至少一条当日记录（通过短时长完成一次专注或 `localStorage` 注入），查看热力图对应时段区块强度高于无记录时段。
- **AC-04**：打开应用页面，断言倒计时、累计时长、当日列表、热力图四个区域在同一视图中同时可见，操作过程无跳转。

测试控制入口不改变产品语义：正常运行（无 `?test=1`）专注阶段仍为 25 分钟、休息阶段 5 分钟。

## 6. 边界

- 不引入服务/API、数据库、认证、后台任务、外部集成或同步层。
- 不生成 `technical-contract.md`、`workspace-bootstrap.json` 或 ADR。
- 跨日数据保留与历史查询、专注时段标签、休息后自动开始下一段专注均为未规定事项，本期不实现。
