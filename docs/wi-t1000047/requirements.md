# 需求：实时时钟页面

## 目标

做一个页面，实时显示当前的时、分、秒。

> 用户明确提出的目标。

## 核心行为与规则

1. 页面加载后，立即显示当前时间的时、分、秒。
2. 时间显示持续更新，秒数变化时页面同步刷新，用户无需手动操作。
3. 时间取自用户设备（浏览器）的本地系统时间。

> 用户明确提出。

## 验收场景

### AC-01：页面实时显示当前时分秒

- 验收条件：页面打开后持续显示当前的时、分、秒，且每秒自动更新。
- 入口类型：用户界面
- 验证动作：打开页面，观察显示的时间值。
- 预期结果：页面显示的时分秒与用户设备当前本地时间一致，且秒数随时间推移自动递增更新。
- 证据类型：runtime-render, interaction
