# 架构基线：实时时钟页面

> 对应批准需求基线：`docs/wi-t1000047/requirements.md`

## 技术路线

- **应用类型**：纯前端 SPA（React + Vite + TypeScript）
- **数据边界**：无服务端、无数据库、无认证、无外部集成。时间取自浏览器本地系统时间（`new Date()`），仅用于即时展示，不持久化、不跨设备共享。

## 页面与交互范围

- 单页面，居中展示当前时、分、秒（`HH:MM:SS` 格式）。
- 页面加载后立即显示当前时间，此后每秒自动更新，用户无需任何操作。
- 时间源为浏览器本地系统时间，与用户设备时钟一致。

## 实现入口与运行方式

- **框架**：React 18 + Vite + TypeScript
- **入口**：Vite 标准入口（`index.html` → `src/main.tsx` → `src/App.tsx`）
- **核心逻辑**：组件挂载时通过 `setInterval` 每 1000ms 读取 `new Date()` 并更新状态；卸载时清除定时器。
- **开发运行**：`npm run dev`（Vite 开发服务器）
- **构建**：`npm run build`（产出静态文件，可部署至任意静态服务器）

## UI 方向

- 纯 CSS 自定义样式，不引入 Ant Design 等组件库。本应用为单一展示型页面，无表格、表单或工作台交互，组件库无法提供额外价值。
- 视觉方向：深色背景、居中大号等宽数字显示，确保时间可读性。不添加无依据的功能或装饰。

## 验证方式

- AC-01 涉及定时器自动更新，验证方式：打开页面后观察显示时间与设备系统时间一致，且秒数每秒自动递增。时间值由 `new Date()` 确定性驱动，可直接比对系统时钟验证正确性；无需额外测试控制入口。
