# 架构基线：专注时段记录系统（k07-timeling）

> 基于 `docs/wi-t1000041/requirements.md`（sha256:45973b19ff65c47ffc1f00148e82ad1e4fcb9263ce6bfffebacece90728e2a3d）

## 1. 路由结论

- 应用类型：`simple-frontend`
- 运行方式：单页面 React/Vite SPA，数据由浏览器 `localStorage` 持久化，不依赖后端服务。

## 2. 页面与交互范围

单页面承载三个视觉区域，从上到下依次为：

1. **累计专注时长区**：显示当日已完成记录的累计专注时长，数值随记录新增即时更新。
2. **番茄钟区**：展示当前阶段名称（专注 / 休息）和剩余倒计时；提供「开始专注」与「停止」操作。
3. **当日记录与热力图区**：
   - 当日列表：按时间顺序展示已完成专注记录（开始时间 + 专注时长）。
   - 热力图：以时段维度展示当日专注分布，专注时长越长的时段颜色越深。

交互行为：

- 用户手动开始专注阶段，倒计时从 25:00 递减；25 分钟自然结束后自动进入 5 分钟休息倒计时。
- 仅专注阶段自然结束生成一条当日记录；手动停止不生成记录。
- 休息结束回到可开始的专注阶段。

## 3. 浏览器状态与数据归属

- **存储介质**：`localStorage`，键名如 `timeling:records:<date>`，按日期分区。
- **记录结构**：`{ id, date, startTimeISO, durationMinutes }`，`durationMinutes` 固定为 25。
- **数据边界**：数据仅在当前浏览器配置文件中保留，刷新或重新打开后仍存在；不与其他浏览器、设备或用户共享，不承诺跨设备同步。
- **应用读写边界**：应用是 `localStorage` 的唯一读写方；不暴露外部写入接口。数据归属与需求「推荐基线」一致。

## 4. UI 组件体系与视觉方向

- 组件库：Ant Design（`antd` 与 `@ant-design/icons`）。
- 视觉方向：浅色工作区，顶部累计时长用醒目大字号呈现；番茄钟居中，阶段名称与倒计时为主要视觉焦点；热力图采用时段网格，以颜色深浅映射专注强度。
- 图标统一使用 Lucide 或 Ant Design 图标，保持单一图标族。

## 5. 实现入口与运行方式

- 新建 React/Vite SPA，开发服务器通过 `npm run dev` 启动。
- 入口文件：`index.html` → `src/main.tsx` → `src/App.tsx`。
- 技术栈：React 18 + TypeScript + Vite + antd。

## 6. 验证方式说明（受定时任务影响的 AC）

本系统涉及番茄钟倒计时，25 分钟专注 + 5 分钟休息的真实时长不利于验收。采用最小应用侧测试控制入口，仅限测试环境使用：

- **AC-01（阶段切换）**：专注/休息阶段切换逻辑可由确定状态直接验证。提供测试参数将专注与休息时长缩短为秒级（如 3s / 2s），观察自动切换。
- **AC-02（自动记录）**：专注阶段自然结束后记录生成逻辑可由缩短后的专注时长触发验证；手动停止不生成记录一并校验。
- **AC-03（累计时长）**：累计为确定状态计算，完成记录后立即校验数值更新。
- **AC-04（热力图）**：热力图由记录数据驱动渲染，完成记录后校验对应时段颜色标记。
- **AC-05（刷新保留）**：写入 `localStorage` 后刷新页面，校验记录、累计时长与热力图恢复一致。

测试控制入口通过环境变量或 URL 参数启用缩短时长，正常运行仍按产品要求执行 25 分钟 / 5 分钟。
