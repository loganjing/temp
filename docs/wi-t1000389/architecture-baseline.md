# 教师管理系统 — 架构基线

> 本文档基于已批准的需求基线 `docs/wi-t1000389/requirements.md`（sha256: 44b0de75f16b6e1a923c9b076937fb28df9e57c1d8fb6ce4f82eb8dbf29c7196），描述教师管理系统的技术承载方式。产品语义以需求基线为准，本文档不重复验收场景或业务规则。

## 1. 应用类型

单用户前端应用（simple-frontend）。无服务端、无数据库、无认证、无后台任务、无外部集成。

## 2. 页面与交互范围

应用为单页应用（SPA），包含一个教师管理页面，提供以下交互：

- **教师列表**：以表格形式展示已保存的教师记录，每行显示教师名称、教授课程、年级、手机、邮箱，并提供编辑和删除操作入口。
- **新增教师**：通过表单填写教师名称、教授课程、年级、手机、邮箱，提交保存后创建一条新记录。
- **编辑教师**：点击列表行的编辑入口后，在表单中回填该记录字段值，修改后提交保存覆盖原有数据。
- **删除教师**：点击列表行的删除入口后，移除该记录。

表单提交时对手机和邮箱进行基本格式校验（推荐基线，实现阶段可调整）。

## 3. 数据归属

- 数据存储于浏览器 `localStorage`，由应用负责读写。
- 数据在同一浏览器配置文件中刷新或重新打开页面后仍保留。
- 数据不会与其他浏览器、设备或用户共享。应用不承诺跨设备同步或服务端持久化。

### 3.1 存储结构

- localStorage 键名：`teachers`
- 存储格式：JSON 数组，每个元素为一个教师记录对象，包含字段：`id`（应用生成的唯一标识）、`name`（教师名称）、`course`（教授课程）、`grade`（年级）、`phone`（手机）、`email`（邮箱）。

### 3.2 读写边界

- 新增：生成唯一 `id`，将记录追加到数组并写入 `localStorage`。
- 查看：从 `localStorage` 读取数组并渲染列表。
- 编辑：根据 `id` 定位记录，更新字段后写回 `localStorage`。
- 删除：根据 `id` 从数组中移除并写回 `localStorage`。

## 4. 技术栈与实现入口

- 框架：React + Vite（SPA）
- 语言：TypeScript
- 运行方式：Vite 开发服务器，通过 `npm run dev` 启动，默认在浏览器中访问开发服务器地址。
- 应用入口：标准 Vite React 项目结构，`index.html` → `src/main.tsx` → `src/App.tsx`。

## 5. 组件结构

```
src/
├── main.tsx              # 应用挂载入口
├── App.tsx               # 根组件，管理列表/表单视图切换
├── types.ts              # Teacher 类型定义
├── storage.ts            # localStorage 读写封装
├── components/
│   ├── TeacherList.tsx   # 教师列表，展示记录并提供编辑/删除入口
│   └── TeacherForm.tsx   # 教师表单，用于新增和编辑
└── validation.ts         # 手机和邮箱格式校验
```

## 6. 校验边界

- 手机字段：校验基本手机号格式（如长度和数字模式），防止明显无效输入。
- 邮箱字段：校验基本邮箱格式（如包含 `@` 和域名）。
- 教师名称、教授课程、年级为必填项。
- 校验失败时在表单中提示，不执行保存。
