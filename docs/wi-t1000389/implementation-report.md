# 教师管理系统 — 实现报告

> 基于 `docs/wi-t1000389/requirements.md` 和 `docs/wi-t1000389/architecture-baseline.md`，实现教师管理系统的增删改查功能。

## 1. 实现概述

按照需求基线和架构基线，实现了一个基于 React + Vite + TypeScript 的单页应用，使用浏览器 `localStorage` 作为数据存储。应用提供教师的增、删、改、查四个核心功能。

## 3. 功能实现说明

### 3.1 新增教师（AC-01）

- 用户点击「新增教师」按钮，切换到表单视图。
- 表单包含教师名称、教授课程、年级、手机、邮箱五个字段。
- 教师名称、教授课程、年级为必填项；手机和邮箱为选填项，填写时进行格式校验。
- 提交校验通过后，`storage.ts` 中的 `addTeacher` 函数生成唯一 `id`，将记录追加到 localStorage 数组并写入。
- 保存后返回列表视图，新记录出现在教师列表中。

### 3.2 编辑教师（AC-02）

- 用户在列表中点击「编辑」按钮，表单回填该记录的字段值。
- 修改字段后提交，`updateTeacher` 函数根据 `id` 定位记录并更新字段，写回 localStorage。
- 保存后返回列表视图，列表中该记录显示更新后的数据。

### 3.3 删除教师（AC-03）

- 用户在列表中点击「删除」按钮，`deleteTeacher` 函数根据 `id` 从数组中移除该记录并写回 localStorage。
- 删除后列表立即刷新，该记录不再出现在列表中。

### 3.4 查看教师列表

- 应用加载时从 localStorage 读取教师记录数组并渲染为表格。
- 表格每行显示教师名称、教授课程、年级、手机、邮箱，并在操作列提供编辑和删除按钮。
- 无记录时显示空状态提示。

## 4. 数据存储

- localStorage 键名：`teachers`
- 存储格式：JSON 数组，每个元素为 `{ id, name, course, grade, phone, email }` 对象。
- `id` 由 `Date.now().toString(36) + '-' + Math.random().toString(36).slice(2, 8)` 生成，保证唯一性。

## 5. 校验规则

| 字段 | 规则 |
|------|------|
| 教师名称 | 必填，不能为空 |
| 教授课程 | 必填，不能为空 |
| 年级 | 必填，不能为空 |
| 手机 | 选填，填写时需匹配 `/^1\d{10}$/`（11位数字，以1开头） |
| 邮箱 | 选填，填写时需匹配 `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`（包含 @ 和域名） |

校验失败时在对应字段下方显示错误提示，不执行保存。

## 7. QA 交接信息

- **启动命令**：`npm run dev`，工作目录为项目根目录。
- **访问地址**：http://localhost:5173/
- **测试数据**：无需预置数据，应用首次打开时 localStorage 为空。测试时通过表单手动添加教师记录。
- **数据隔离**：数据存储在浏览器 localStorage，不同浏览器或配置文件之间互不影响。测试前可在浏览器 DevTools 中清除 localStorage 键 `teachers` 以重置状态。

## 8. 遗留风险

- 无认证、无权限控制，数据仅在本地浏览器存储，不适用于多用户共享场景（需求第3节未规定，属预期范围）。
- 手机和邮箱校验为推荐基线格式校验，不保证号码或邮箱真实存在。
- 无分页、排序、搜索等列表增强功能（需求第3节未规定）。
